OmniMux 是**面向 AI Agent 的社交媒体全链路 API**。**一个接口**完成**内容制作与多平台编排**；**按调用付费，无需订阅**。以 REST API、本地 CLI、Agent Skill、MCP Server 四种形态交付，任何 Agent 都能接入。**全球渠道**：X、LinkedIn、YouTube、Instagram、TikTok、Threads 等统一抽象与鉴权（产品支持矩阵不包含中国大陆境内平台）。**Agent 协同交付**：把官网发给 Agent，安装、初始化与平台授权可由 Agent 自助完成。

生产入口：控制台 [omnimux.ai/dashboard](https://omnimux.ai/dashboard) · API `https://api.omnimux.ai` · 文档 [docs.omnimux.ai](https://docs.omnimux.ai)。

## 服务能力

### 内容制作

多渠道内容生成与素材生产能力，以 API 与 Skill 形式供 Agent 调用，由你的 Agent 主导创意与取舍。

### 多平台编排

在全球渠道上完成执行闭环。编排子能力包括：

- **发布** 多渠道发帖与排期，按平台规则落地
- **适配** 按渠道改写格式、规格与语气
- **分发** 多账号矩阵分发，拟人节奏，可审计
- **回收** 互动与表现数据回流，供复盘与下一轮规划

消息触达、推广投放等能力随渠道矩阵开放，作为编排层扩展。

以上能力覆盖同一调用面：一个 API，内容制作 + 多平台编排。

## 核心能力

**统一鉴权**
一个 Key 调用全部能力，跨制作与编排的凭证统一管理。

**可审计执行**
幂等发布，每次调用的请求、响应、延迟与成本完整留痕。

**拟人节奏**
执行策略拟人、有节奏、可配置，把平台规则当约束条件。

**稳定调度**
上游抖动时智能路由自动切换到健康通道，调用契约与计量方式保持不变。
