## 如何保管 API Key？

- 不要把 `sk-` 写入公开仓库、前端打包产物或截图
- 使用环境变量或密钥管理服务
- 泄露后立即在控制台轮换或作废
- 开发、预发、生产分别使用密钥，便于撤销

## 两套凭据

| 凭据 | 用途 |
| --- | --- |
| `sk-` API Key | 向 `https://api.omnimux.ai` 发起模型请求，可消费账户额度 |
| 个人访问凭据 | 调用 `https://omnimux.ai` 的本人用户接口，如社媒发布、账户查询；不是模型生成密钥 |

不要用个人访问凭据替换网关 `sk-`。下述权限只限制已有功能的访问，不代表新模型上架、价格变化或获得管理员资格。

## 个人限定权限访问凭据

个人限定权限访问凭据与下述设备码登录行为已于 **2026 年 10 月 4 日上线**。

### 创建与管理

在浏览器登录后，打开账户安全页，创建访问凭据：填写易辨认的名称，只选择任务所需权限，并设置有效期。表单默认 **30 天**。手动凭据若要永不过期，必须明确选择“永不过期”，页面会提示风险；默认不是永久有效。

完整的 `nap_...` **只在创建成功时返回一次**。关掉弹窗前保存到私密位置。之后列表只显示名称、权限、到期时间、使用记录和脱敏提示，不再显示完整明文。丢失后请创建替代凭据，无法再次取回原明文。

每枚手动凭据可独立撤销；撤销一枚不会撤销其他手动凭据。查看、创建、改名和撤销访问凭据都需要**已登录的浏览器会话**，不能用凭据再创建或撤销另一枚凭据。浏览器会话管理与试用区生成也仍仅限浏览器。创建或撤销须完成针对准确操作的安全验证；验证不会扩大权限。

个人访问凭据管理接口为 `/api/user/access_tokens`，`/catalog` 返回当前可选权限，`/scopes` 返回权限名称说明。创建时须明确传 `expires_at`：漏填或 `null` 会被拒绝；`0` 表示明确选择永不过期，不是默认值。这是浏览器专用的个人管理入口，不是新增管理员接口。不要再通过旧单凭据创建入口 `/api/user/token` 签发新凭据。

### 按用途选择权限

`read` 表示查看或查询，`write` 表示修改或创建对应资源。`api_key:reveal` 单独允许读取完整的**网关 API Key**，不是再次显示个人凭据；授予它可能暴露可消费额度的密钥。

| 资源 | 权限示例 | 可做什么 |
| --- | --- | --- |
| 本人资料 | `profile:read` | 查看本人资料、分组与可用模型 |
| 网关 API Key | `api_key:read`、`api_key:write`、`api_key:reveal` | 查看密钥设置；创建、修改、删除密钥；读取完整密钥 |
| 本人使用记录 | `usage:read` | 查看用量日志、统计、任务和审计记录 |
| 社媒发布 | `social:read`、`social:write` | 查询连接账户、帖子与分析；连接、解绑、发布、上传媒体和同步 |
| 托管频道 | `hosted:read`、`hosted:write` | 查询本人订单、频道和任务；订购、续费、修改品牌、处理任务和上传媒体 |
| 灵感库 | `inspiration:read`、`inspiration:write` | 查询私有灵感与媒体；创建直链分享，不包含管理库内容的编辑 |
| 本人文件 | `files:read`、`files:write` | 查询存储额度；上传文件和创建、确认上传凭证。`/api/v1/files` 与 `/v1/files` 权限一致 |
| 达人工作台分类 | `influencer:read` | 查询分类，不是生成权限 |

当前浏览器权限目录决定账户实际可选项。凭据不能扩大账户角色、资源归属或余额。只读凭据不能执行写操作。发布、订购等操作仍按已有业务规则计费，授予权限不意味着免费。

### 请求时带哪套凭据？

允许使用个人凭据的用户接口向 `https://omnimux.ai` 发送 `Authorization: Bearer <personal_access_token>`。用户身份由凭据决定。旧示例可为客户端兼容保留 `New-Api-User: <user_id>`，但这个请求头**不参与鉴权**，不能指定另一个用户或增加权限。

未提供、无效、过期或已撤销的凭据不能授权请求。有效凭据若缺少权限、访问浏览器专用入口，或访问未声明支持个人凭据的路径，也会被拒绝。恢复办法见[连接与使用](/zh/faqs/connection-usage)。

### 原有单凭据如何迁移？

旧单访问凭据采用**全服务统一停用截止时间**：升级后的服务首次初始化该时间起，再保留 30 天。重启或增加节点不续期。不是每台客户端、每次请求重新获得 30 天；到期停用也不等于抹除旧存储记录。

请在截止前，用新限定权限凭据或[设备码登录](/zh/api-reference/account/device-login)重新连接自动化工具。截止后，持有旧凭据的客户端必须**重新登录**。旧凭据不会自动转成新凭据。该迁移不影响 `sk-` 网关密钥，修改 `New-Api-User` 也不能绕过。所有旧凭据客户端共用的生产环境停用截止为 **2026 年 11 月 3 日 13:52:36 UTC**（`2026-11-03T13:52:36Z`）。

## 最小权限习惯

- 两套凭据都不要出现在日志或截图中
- 只给任务所需权限、模型和分组
- 分享示例时使用 `<token>` 占位符
