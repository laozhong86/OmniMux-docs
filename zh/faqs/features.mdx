## 兼容 OpenAI 吗？

文本/多模态网关主路径兼容 **OpenAI Chat Completions** 等常见格式：把客户端 Base URL 指到 `https://api.omnimux.ai/v1`，使用 OmniMux `sk-` 与 **live model id** 即可。详见 [语言系列完整参数](/zh/api-reference/text-series/claude/complete)。

## 支持哪些模态？

以控制台 live 目录为准，文档按系列组织：

- 语言 / 图像 / 视频  
- 社交数据（读）与社媒发布（写，凭证不同）  

未在定价中的模型不要假设可用。

## 为什么和官网 ChatGPT / Claude 网页版体验不同？

API 提供的是**模型能力本身**，不包含各官网的产品壳（联网、记忆、内置工具 UI 等）。若需要接近产品壳的体验，需自行维护上下文、system prompt 与工具调用。

## 视频任务怎么查？

创建：`POST /v1/video/generations`  
轮询：`GET /v1/video/generations/{task_id}`（[查询视频任务](/zh/api-reference/tasks/video-task)）  
不要与 OpenAI Videos 的 `/v1/videos/{id}/content` 下载路径混淆。

### 角色工作台的参考视频检查

<Note>
这些检查针对角色工作台的参考视频准备，不代表上方通用视频接口的所有请求都采用这些规则。

工作台会在生成前检查实际媒体内容，不只相信文件名、浏览器显示时长或调用方填写的时长。完整原始参考素材必须为 **4 至 30 秒**，包含两个端点；视频或尾部音轨超长会直接拒绝，不自动裁切或加速。填写的整数时长须与实际时长四舍五入后的值一致；明确填写的画面比例须匹配实际呈现画面。

接收上限仍为 **100 MiB（104857600 字节）**。这是工作台接收上限，不是每个供应商选项已确认的限制；各选项完整的输入容量、格式、帧率与分辨率契约仍未核实。合法的小文件不需要强制压缩，自动压缩尚未启用，也不承诺任意大文件处理或全面格式兼容。工作台支持完整的单视频流 MP4/MOV、H.264/H.265 编码及受支持的音轨；不确定的呈现时间线或不受支持的媒体可能被拒绝。

生成会使用服务器准备的原字节副本，不对已通过检查的视频重新编码；视频中的完整内置音轨保留。只有 **不超过 15 秒**、且能够完整提取音轨的短参考素材，才会附加单独的可选音频参考；较长素材不会被替换为剪短的音频附件。这不保证生成结果复现每一句原声或每一种声音。

媒体准备拒绝发生在**生成扣费之前**。实际媒体不合法返回 `400 reference_video_invalid`；填写的时长或明确比例不匹配返回 `400 invalid_request`；取消或媒体检查超时返回 `408 reference_video_invalid`；准备繁忙，或检查、存储、下载暂不可用返回 `503 reference_video_invalid`。错误使用安全提示，不暴露签名素材链接或原始诊断细节。这些是媒体准备规则，不代表后续所有生成失败都不收费。

上传保留原始文件名，包括空格或 `#`，合法文件无需先改名。上传或准备失败时，页面优先显示服务返回的安全原因，不会一律建议换更小的文件。实际时长超过 30 秒时，生成不会开始，提示会说明视频不会自动剪短。文件和媒体检查仍然适用。
</Note>

## 创建网红时可以使用风格参考图吗？

**创建网红**流程支持一张可选的 **JPEG、PNG 或 WebP** 风格参考图，大小不超过 **5 MiB（5,242,880 字节）**。这是该网站流程的限制，不是公开生图接口新增的限制。

参考图用于借鉴轮廓、造型、配色、服装和整体气质，**不锁定人物身份**，结果可以是新角色或不同人物。输入冲突时，**明确文字描述优先于所选特征，所选特征优先于图片参考**；所选夸张程度仍然适用。

只提供参考图、不填写描述或选择特征，也可以提交。这一路径要求生成**白底、单人、全身角色图**，不照搬参考图的背景、文字或标志。仅图、图片加文字及特征、同样文字及特征但不带图片的三类核验均生成成功；这不代表每次请求都保证成功。本说明不承诺多视图等其他模式的效果。

`/pg/influencer/sheet` 是网站登录会话使用的内部路径，不是供网关 Bearer（`sk-`）凭证调用的公开接口，也不是 `/v1` 接口。本次改动**不新增或改变公开生成接口的请求格式**。外部集成仍使用既有的 [GPT Image 生图接口说明](/zh/api-reference/image-series/gpt-image/generate)。
