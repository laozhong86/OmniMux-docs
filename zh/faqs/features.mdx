## 兼容 OpenAI 吗？

文本/多模态网关主路径兼容 **OpenAI Chat Completions** 等常见格式：把客户端 Base URL 指到 `https://api.omnimux.ai/v1`，使用 OmniMux `sk-` 与 **live model id** 即可。详见 [语言系列完整参数](/zh/api-reference/text-series/claude/complete)。

## 支持哪些模态？

以控制台 live 目录为准，文档按系列组织：

- 语言 / 图像 / 视频  
- 社交数据（读）与社媒发布（写，凭证不同）  

未在定价中的模型不要假设可用。

## 系统更新显示哪个版本？

管理员的系统更新检查读取 **OmniMux 本站最近成功上线的版本公告**。公告在部署与健康检查成功后自动发布，独立于当前运行的应用，包含上线版本和发布时间。

它不是上游尚未上线的更新清单，检查公告也不会升级系统。查看详情会打开当前语言的 [API 更新](/zh/updates)页。若两个本站构建的上游版本号相同、构建标识不同，仅凭这种差异无法判断哪个较新，也不表示应当回退。

公告不可用或格式异常时仍会报错；展示的上次结果会标为缓存，不能据此认定本次检查成功。旧更新来源的结果不会继续作为新来源的结果使用。

## 插件安装为什么提示能力不支持？

插件市场的新版可能要求当前网关尚未具备的能力。出现 `unsupported or duplicate required capability "json-order@1"` 一类提示，表示能力声明不受支持或重复，与密钥、账户余额无关。管理员应核对插件的具体版本与宿主支持情况，再启用插件。直接删除声明不能解决兼容问题：依赖成员顺序的调用需要完整保留请求顺序的处理链。

插件兼容不代表模型已上架、渠道已启用、价格已调整，也不代表供应商调用已经成功。仍以当前可访问的模型目录与已发布调用说明为准。

## 转换调用格式时要注意什么？

网关在 Chat Completions、Responses、Claude、Gemini 格式之间转换时，会按媒体实际类型及目标格式映射内容。目标无法承载的媒体类型可能在转换时省略；收到成功响应不等于原始输入全部参与处理，请检查实际返回内容。

思考设置取决于具体模型和供应商线路。不支持的强度可能调整或移除；无法关闭思考的模型可能采用其支持的最低设置。只有管理员启用了对应适配，模型后缀才会转换为思考设置。不同模型收到同一强度，不代表使用相同的计算预算。

对于 Gemini 工具参数与结构化输出，无法装入旧式结构定义的约束，可在支持的 Gemini v1beta 或 Vertex AI 线路中使用原始 JSON Schema。Gemini v1 仍使用旧式转换，可能丢失不支持的约束；适用于旧式格式的定义也可能被规范化处理。这不承诺所有线路都完整支持全部 JSON Schema 关键字。工作流使用结果前仍须校验实际结构。

## 为什么和官网 ChatGPT / Claude 网页版体验不同？

API 提供的是**模型能力本身**，不包含各官网的产品壳（联网、记忆、内置工具 UI 等）。若需要接近产品壳的体验，需自行维护上下文、system prompt 与工具调用。

## 视频任务怎么查？

创建：`POST /v1/video/generations`  
轮询：`GET /v1/video/generations/{task_id}`（[查询视频任务](/zh/api-reference/tasks/video-task)）  
不要与 OpenAI Videos 的 `/v1/videos/{id}/content` 下载路径混淆。

### 自动时长是否适用于所有视频？

只有当前安装的插件明确声明自动时长能力，且对应模型的调用说明允许时，通用视频接口才可用 `-1` 表示由供应商决定时长。预扣按该模型支持的最长时长计算，完成后按报告的实际用量结算；正数时长继续遵循模型各自的限制。不能只凭插件市场展示就假定已支持自动时长。

这不会改变下方角色工作台的参考素材要求：动作迁移输入为 **2 至 30 秒**，对象替换输入为 **4 至 30 秒**，成片仍为 **4 至 30 整数秒**。通用插件支持自动时长，不会绕过该流程对文件、媒体、画幅或时长的检查。

### 角色工作台的参考视频检查

<Note>
这些检查针对角色工作台的参考视频准备，不代表上方通用视频接口的所有请求都采用这些规则。工作台目前接收**一段参考视频**，模型的多视频数量上限不代表网站已提供多视频输入功能。
</Note>

工作台会在生成前由服务器检查真实媒体。合法参考视频无需匹配 16:9、9:16 等成片比例，但须同时满足以下要求：

| 输入项目 | 支持范围 |
| --- | --- |
| 文件容器与视频编码 | MP4 或 MOV；H.264/AVC 或 H.265/HEVC |
| 内置音轨（如有） | MP4：AAC、MP3；MOV：AAC、MP3、PCM |
| 文件大小 | 不超过 **200 MiB（209,715,200 字节）** |
| 素材时长 | 动作迁移：**2 至 30 秒**；对象替换：**4 至 30 秒** |
| 呈现画面宽高比（宽÷高） | **0.4 至 2.5**，含端点，为连续范围，不是固定比例名单 |
| 宽度与高度 | 各为 **300 至 6000 像素** |
| 总像素（宽×高） | **407,696 至 8,295,044** |
| 帧率 | 每秒 **24 至 60 帧** |

例如，5:4、1:1、4:3、21:9 等比例只要同时满足其他条件，就可以作为参考。工作台以明确字节数限制文件大小，文件管理器显示的“MB”可能采用不同计量方式。

参考输入与生成输出分别处理。**动作迁移**的参考素材可以短于成片，独立选择的成片时长仍为 **4 至 30 整数秒**；成片画幅以所选清晰度下展示的选项为准（480P：16:9、9:16、3:4；720P：16:9、9:16）。

**对象替换**保留现有标准画幅方式。实际提交时，服务器核对原视频画幅是否匹配所选清晰度可用的成片比例：**480P 支持 16:9、9:16、3:4；720P 支持 16:9、9:16**。实际 **4 至 30 秒**原片时长四舍五入为整数秒后请求生成，例如 9.708 秒原片对应 10 秒生成请求，沿用按该请求时长计费的规则。**仍未启用自动沿用原片画幅与时长的专用编辑方式。**

合法的 5:4 参考视频可以选入并保留，不在素材区显示画幅红字。对象替换无法保留该画幅时，只在实际提交后通过**顶部气泡消息**说明：“参考视频已通过检查，但当前生成服务暂不能保留该画幅进行对象替换。素材已保留，可使用动作迁移。”该拒绝发生在任务分发与生成扣费之前。工作台不会为适配输入而静默裁切、拉伸、补边、截短、加速或切换创作模式；生成内容本身也可能与原片有差异。

浏览器不能播放或读取元数据，不会单独成为素材不合法的依据，服务器会继续核对。Desert Duo 预设生成时使用对应高清参考片，卡片保留轻量预览。候选素材检查失败时，保留最后一次有效选择。具体的上传、素材准备或服务问题使用工作台的**顶部气泡消息**提示，不在参考区保留红字。临时服务失败可重试，不会把合法画幅说成“不支持”。

`POST /pg/influencer/motion/inspect` 是网站登录会话使用的内部素材预检，不调用生成模型，也不扣生成积分；它**不是**供网关 Bearer（`sk-`）凭证调用的公开接口，也不是 `/v1` 集成入口。正式生成会再次校验，预检通过不代表后续生成必定完成。

完整原始视频及音轨会在安全隔离环境中完整解码，不只相信文件名或调用方填写的时长。视频或尾部音轨超长会拒绝，不自动剪短；不明确的呈现时间线仍会拒绝。AAC 容器时间记录每段最多允许一个采样点的舍入误差，时间线须连续，累计漂移不得超过一个采样点；末尾长度与编码补齐部分约束的是同一可播放范围，只扣除一次。

生成使用服务器准备的已校验原字节副本，不重新编码，保留视频中的完整内置音轨。只有**不超过 15 秒**且能完整提取音轨的参考片，才附加单独的可选音频参考；较长素材不会被替换为剪短的音频附件。这不保证生成结果复现每一句原声或每一种声音。

媒体准备拒绝发生在**生成扣费之前**。实际媒体检查不通过返回安全的 `400 reference_video_invalid`；方式、输出选项或编辑专用准备等请求设置不合法时，也可能返回 `400 invalid_request`；取消或检查超时返回 `408 reference_video_invalid`；准备繁忙，或检查、存储、下载暂不可用返回 `503 reference_video_invalid`。安全提示不暴露签名素材链接或原始诊断细节。这些准备规则不代表后续所有生成失败都不收费。

上传保留原始文件名，包括空格或 `#`，合法文件不必先压缩或改名。尚未启用自动压缩或不支持格式的自动转换。文件归属、有效期、下载限制和真实媒体检查仍然适用。

### 对象交换如何使用参考图片

<Note>
本节说明修订后的默认指令。文档发布不代表生产工作台已更新，实际可用性以已部署的网站版本为准。
</Note>

对象交换的默认提示会让视频生成模型结合原视频与**全部参考图片**，自行判断各图提供的是身份、物品还是局部外观，优先理解参考图完整主要对象及其表达用途，优先选择同类、同用途的合理目标；同等匹配时再选择对无关内容影响最小的对应。同类合理目标存在时，不跨到无关类别。图片顺序只用于指代，**不再默认用图片 1 替换人物**。不填写个人提示词也可提交；流程不增加额外识别模型，也不要求用户点选目标。

参考服饰时，提示要求保留原人物身份、身体和其他穿戴，不会自动把服饰图中的模特当作换脸参考；参考商品时，要求保留使用者、服装与环境，不照搬商品图背景。同一物品的多个角度共同定义一个物品。模型可以适配目标的轮廓、尺度、透视、材质、衣褶、阴影及必要接触，同时沿用原动作和镜头顺序。

有效且明确传入的个人补充优先；工作台中的个人提示开关决定是否发送该草稿。已保存角色经过核验的身份与物种，仅在该图实际作为身份参考时适用。提示要求非目标人物、物品、场景、时序与原音保持一致；这些是**生成目标，不保证每次都精确保留或正确理解对应关系**。

当前 **10 项内置对象交换侧栏预设**保留原说明、预览与参考视频，但其通用展示句不再作为生成补充发送。本次没有改变探索区的应用行为或社区任务描述。

这些默认规则也用于既有的角色视频创建集成入口。本次不改变公开请求或响应字段、时长规则、画幅选项与计费设置，不会向任意通用视频请求自动添加这些提示，也不启用自适应画幅或自动沿用原片时长的编辑方式。

### 浏览器传输

角色工作台的 R2 直传和已存产物直下已于 2026 年 10 月 12 日上线。参考素材沿用既有申请凭证 → 原始 File PUT → 确认流程，只有明确的 501 能力不支持响应才回退表单上传，详见[上传规则](/zh/api-reference/file-series/upload-stream)。R2 HEAD 确认只检查大小和类型元数据，不替代上方的真实参考媒体检查。

浏览器预览或下载可在受支持的任务产物地址请求直下，下载还要求最终 R2 响应按附件返回；提供给模型的规范参考地址仍返回字节。首次从上游回存和参考准备仍使用服务器。当前桶凭公开链接可读，不是私密存储，签名地址不保证立即撤销，详见[下载与访问边界](/zh/api-reference/file-series/download)。生产浏览器验收已覆盖图片和视频直传、图片和视频附件保存，以及视频播放与拖动；未做速度对比，不声称提速倍数。

## 创建网红时可以使用风格参考图吗？

**创建网红**流程支持一张可选的 **JPEG、PNG 或 WebP** 风格参考图，大小不超过 **5 MiB（5,242,880 字节）**。这是该网站流程的限制，不是公开生图接口新增的限制。

参考图用于借鉴轮廓、造型、配色、服装和整体气质，**不锁定人物身份**，结果可以是新角色或不同人物。输入冲突时，**明确文字描述优先于所选特征，所选特征优先于图片参考**；所选夸张程度仍然适用。

只提供参考图、不填写描述或选择特征，也可以提交。这一路径要求生成**白底、单人、全身角色图**，不照搬参考图的背景、文字或标志。仅图、图片加文字及特征、同样文字及特征但不带图片的三类核验均生成成功；这不代表每次请求都保证成功。本说明不承诺多视图等其他模式的效果。

`/pg/influencer/sheet` 是网站登录会话使用的内部路径，不是供网关 Bearer（`sk-`）凭证调用的公开接口，也不是 `/v1` 接口。本次改动**不新增或改变公开生成接口的请求格式**。外部集成仍使用既有的 [GPT Image 生图接口说明](/zh/api-reference/image-series/gpt-image/generate)。
