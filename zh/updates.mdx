<a id="2026-09-06-account-quota-errors"></a>

<Update label="2026 年 9 月 6 日" tags={["平台", "文本"]} rss={{ title: "OpenAI 文本接口统一账户额度错误" }}>

  OpenAI Completions、Chat Completions、Responses 和 Responses Compact 在本地账户余额或订阅额度不足以完成预扣时，返回 HTTP **402**，`error.type` 与 `error.code` 均为 `insufficient_quota`。流式请求在 SSE 建立前返回 JSON 错误。应先检查余额或额度，再决定是否重新请求；不要将其当作密钥失效或临时限流。token 错误、上游渠道错误、其他协议，以及真正的 401/403、普通 429 和 5xx 行为保持不变。

  ### 链接

<a id="2026-08-25-social-analytics-reader-seats"></a>

<Update label="2026 年 8 月 25 日" tags={["平台", "文本"]} rss={{ title: "上线社媒分析与私信分析套件、Jina Reader 网页提取及社媒席位管理" }}>

  ## 社媒分析与私信分析套件

  OmniMux 在 `/api/social/v1` 路由组下全新接入 11 个 RESTful 深度数据分析与私信洞察端点：

  - **社媒分析（Analytics）：** 宏观大盘时序指标、7×24小时最佳发布时间热力矩阵、发帖频次与互动率相关性模型、内容生命周期衰减曲线、多平台粉丝增长快照、单帖与列表深度指标排行、外部平台存量帖子增量同步。
  - **私信分析（Inbox Analytics）：** 私信与互动消息量时序走势、响应时效（TTR）耗时分布、7×24小时私信时段热力图、跨平台私信渠道来源占比。

  ## Jina Reader 网页提取中继（`POST /v1/reader`）

  - **模型 ID：** `jina-reader-v1`
  - **能力：** 将网页 URL 高效转换为大模型友好的 Markdown 或结构化 JSON 文本，支持 CSS 选择器过滤、图片摘要与按输出 Token 结算。
  - **鉴权：** 标准网关 Bearer `sk-...` 凭据。

  ## 社媒席位管理（`GET /api/social/v1/seats`）

  - 查询当前用户绑定的社媒账号数量、席位配额容量与可用空坑状态。

  ### 链接

  - [Jina Reader 网页提取](/zh/api-reference/reader-series/models/jina-reader-v1)
  - [大盘时序指标](/zh/api-reference/publishing/analytics/daily-metrics)
  - [查询席位](/zh/api-reference/publishing/seats)

</Update>
