## 平台 | API 更新日志上线

`平台`

*面向开发者的公开时间线：模型上新、能力变更、定价与平台说明。*

OmniMux 现提供 **API 更新** 时间线，便于跟踪网关侧模型与协议变更，而无需翻聊天或零散发布说明。

## 本时间线覆盖范围

- **新模型** — 线上定价新增可调用的模型 ID
- **模型更新** — 新模式、时长、分辨率、参数
- **价格调整** — 实质费率或结算规则变化
- **不兼容变更** — 请求/响应或路径不兼容
- **平台** — 鉴权、域名、公开 HTTP 面（如社媒发布）

## 当前使用入口

| 面 | URL |
| --- | --- |
| 控制台 | `https://omnimux.ai` |
| OpenAI 兼容 API | `https://api.omnimux.ai/v1` |
| 文档 | `https://docs.omnimux.ai` |
| 状态页 | `https://status.omnimux.ai` |

Relay 鉴权：控制台签发的 Bearer `sk-…`。

日期为 **2026-08-09**、描述语言 / 图像 / 视频 / 社交数据等族的条目，记录的是本时间线上线时网关上 **已可调用** 的能力，**不是**伪造的逐模型首发史。之后条目为只追加的真实变更。

## 新模型 | 视频生成 — Omni Flash / MiniMax H3 / Veo / Kling / Seedance

`新模型`

*本时间线上线时已可用的异步视频能力：先创建任务再查询状态。*

OmniMux 视频生成以 **异步任务** 为主，且 **已在** 网关可调用：

- 创建：`POST /v1/video/generations`
- 查询：`GET /v1/video/generations/{task_id}`

## 新模型

| 模型 ID | 角色 |
| --- | --- |
| `omni_flash`、`omni_flash-4s` / `-6s` / `-10s` | Omni Flash 时长族 |
| `minimax-h3-t2v` | MiniMax H3 文生视频 |
| `minimax-h3-flf` / `minimax-h3-fl2va` / `minimax-h3-endframe` | MiniMax H3 图/帧变体 |
| `veo_3_1` | Veo 3.1 |
| `grok-imagine-video-1.5` | Grok Imagine Video |
| `ltx2.3-kj` | LTX 系 SKU |
| `kling-v2-6`、`kling-v3` | 线上定价中的 Kling 视频 |
| `seedance-2-0`、`seedance-2-0-fast`、`seedance-2-0-mini`、`seedance-2-5` | 线上定价中的 Seedance 族 |

## 关键能力

- 提交一次后轮询任务状态直至产出就绪
- 勿与纯内容下载路径混淆

## 文档

见 **视频系列** 与 **任务管理**。精确 ID 始终以线上定价为准。

## 新模型 | 社交数据 — TikTok / Instagram / X / YouTube（只读）

`新模型`

*只读社交数据模型（Chat Completions 形态模型 ID）——不是社媒发布。*

**社交数据**是 **只读** 的公开内容/资料类能力，**不是** 社媒发布。

## 新模型

| 平台 | 模型 ID |
| --- | --- |
| TikTok | `tiktok-user`、`tiktok-posts`、`tiktok-video`、`tiktok-search` |
| Instagram | `instagram-user`、`instagram-posts`、`instagram-post`、`instagram-search` |
| X | `x-user`、`x-posts`、`x-tweet`、`x-search` |
| YouTube | `youtube-user`、`youtube-posts`、`youtube-video`、`youtube-search` |

## 社媒发布（另一套面）

连接账户与发帖走 **`/api/social/v1/*`**，鉴权为 access token + `New-Api-User`，见 API 手册 **社媒发布**。勿与网关 `sk-` Chat Completions 混用鉴权。

见 API 手册 **社交数据** 分组（下方链接）。
