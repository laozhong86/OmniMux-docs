## API 更新日志上线

**2026-08-09** · `期初目录`

*面向开发者的公开变更流：模型上新、能力扩展、定价与 breaking change。*

OmniMux 现提供 **API 更新日志**，便于跟踪网关侧模型与协议变更，而无需翻聊天记录。

## 本日志覆盖范围

- **模型上新** — live pricing 上可调用的新 model id
- **能力扩展** — 新模式、时长、分辨率、参数
- **定价** — 实质费率或结算规则变化
- **Breaking** — 不兼容的请求/响应或路径变更
- **平台** — 鉴权、域名、公开 HTTP 面（如社媒发布）

## 当前使用入口

| 面 | URL |
| --- | --- |
| 控制台 | `https://omnimux.ai` |
| OpenAI 兼容 API | `https://api.omnimux.ai/v1` |
| 文档 | `https://docs.omnimux.ai` |
| 状态页 | `https://status.omnimux.ai` |

Relay 鉴权：控制台签发的 Bearer `sk-…`。额度展示：raw_quota ÷ 500000 = USD；**1 USD = 10 积分**。

## 社交数据模型（目录期初）

**2026-08-09** · `期初目录`

*只读社交数据：以 Chat Completions 形态提供的 TikTok、Instagram、X、YouTube 模型。*

**模型:** `instagram-post`, `instagram-posts`, `instagram-search`, `instagram-user`, `tiktok-posts`, `tiktok-search`, `tiktok-user`, `tiktok-video`, `x-posts`, `x-search`, `x-tweet`, `x-user`, `youtube-posts`, `youtube-search`, `youtube-user`, `youtube-video`

**社交数据**是 **只读** 的公开内容/资料类能力，**不是** 社媒发布。

## 本期初平台

| 平台 | Model id（示例） |
| --- | --- |
| TikTok | `tiktok-user`、`tiktok-posts`、`tiktok-video`、`tiktok-search` |
| Instagram | `instagram-user`、`instagram-posts`、`instagram-post`、`instagram-search` |
| X | `x-user`、`x-posts`、`x-tweet`、`x-search` |
| YouTube | `youtube-user`、`youtube-posts`、`youtube-video`、`youtube-search` |

## 社媒发布（另一套面）

连接账户与发帖走 **`/api/social/v1/*`**，鉴权为 access token + `New-Api-User`，见 API 手册 **社媒发布**。勿混用鉴权模型。
