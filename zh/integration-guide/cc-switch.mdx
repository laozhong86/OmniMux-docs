<Note>
Base URL：`https://api.omnimux.ai`（OpenAI 兼容客户端通常填 `https://api.omnimux.ai/v1`）。在 [控制台](https://omnimux.ai/dashboard) 创建 `sk-` API Key。模型 ID 以控制台或 `GET /v1/models` 为准。
</Note>


## 准备

1. 安装 CC Switch（Claude Code / 多模型切换工具，以官方发布渠道为准）
2. OmniMux API Key

## 配置

1. 新增 OpenAI 兼容提供商或自定义端点
2. Base URL：`https://api.omnimux.ai/v1`（或工具要求的根地址 `https://api.omnimux.ai`）
3. API Key：`sk-...`
4. 选择/填写模型 ID

## 验证

切换到 OmniMux 配置后执行一次对话或代码补全。
