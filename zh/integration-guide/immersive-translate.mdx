<Note>
Base URL：`https://api.omnimux.ai`（OpenAI 兼容客户端通常填 `https://api.omnimux.ai/v1`）。在 [控制台](https://omnimux.ai/dashboard) 创建 `sk-` API Key。模型 ID 以控制台或 `GET /v1/models` 为准。
</Note>


## 准备

1. 安装 [沉浸式翻译](https://immersivetranslate.com/) 浏览器扩展
2. OmniMux API Key

## 配置

1. 扩展设置 → **翻译服务** → 添加 **OpenAI** / 自定义 OpenAI
2. API Key：`sk-...`
3. 自定义 API 地址：`https://api.omnimux.ai/v1`
4. 模型：选择或填写 OmniMux 文本模型 id

## 验证

打开网页启用翻译，确认译文返回正常。
