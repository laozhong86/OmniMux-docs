> - 使用 `multipart/form-data` 格式直接上传本地文件或二进制数据流
> - MP4/MOV 视频最大 **200 MiB（209,715,200 字节）**；其他文件最大 **100 MiB（104,857,600 字节）**
> - 文件会在 **72 小时** 后自动过期并由后台服务物理清理
> - 单用户最多存储 **2,000** 个活跃文件，配额耗尽时会返回 429 提示
> - 鉴权：`Authorization: Bearer sk-...`

## 浏览器直传

<Note>
浏览器直传已于 2026 年 10 月 12 日上线，既有表单上传接口仍保留。
</Note>

使用既有 `POST /api/v1/files/upload/presign` 和 `POST /api/v1/files/upload/confirm`（也支持 `/v1/files/upload/*`），不要混用社媒发布的媒体预签名接口。申请凭证和确认请求沿用文件上传的既有鉴权，正文均为 JSON：申请凭证要求非空字符串 `file_name` 和 `mime_type`、正整数字节数 `file_size`，以及可选字符串 `upload_path`；确认要求字符串 `file_id` 和相同的整数 `file_size`。标准响应使用 `success`（布尔值）、`code`（整数）、`msg`（字符串），成功时包含 `data`。凭证数据包含 `file_id`、`upload_url`、`upload_method`、`upload_headers`（字符串到字符串的映射）、`resource_url`、`download_url` 和 `expires_at`。

上传凭证默认有效 **15 分钟**，最长不超过 **1 小时**。凭证的 `data.expires_at` 是上传截止时间，不是确认后文件的保留截止时间。

1. 申请凭证时传入 `file_name`、`mime_type`、大于零的字节数 `file_size`，以及可选的 `upload_path`。MP4/MOV 视频上限为 **200 MiB（209,715,200 字节）**，其他文件为 **100 MiB（104,857,600 字节）**，具体网站流程可以有更低限制。普通上传由视频 MIME 类型或 `.mp4`／`.mov` 文件名决定读取额度，但超过 100 MiB 的文件还必须通过真实 MP4/MOV 容器检查；改后缀不能放行非视频文件。下文参考视频浏览器检查用途采用单独策略。Base64 上传解码后的文件仍限制为 100 MiB。
2. 将浏览器原始 `File` 作为请求正文，按 `data.upload_method` 直接 PUT 到 `data.upload_url`，原样携带所有 `data.upload_headers`。这些是必需的签名请求头，包括 `If-None-Match: *`，重复使用凭证不能覆盖已存在的对象。不要使用 `FormData` 包装文件，不要使用本站已鉴权的请求客户端，也不要附加本站 Bearer 请求头；设置 `credentials: "omit"`。
3. PUT 成功后，用 `file_id` 和相同的 `file_size` 确认。只有确认成功后，才将返回的文件地址和保留期限加入既有上传库；凭证里的 `resource_url` 不能证明文件已确认。

**只有**申请凭证接口返回明确的 **501** 存储不支持响应，才改用表单上传。鉴权、配额、网络、PUT 或确认失败都不能静默转为服务器中转或重试文件，应保留服务返回的安全 `msg` 提示。

确认通过 R2 **HEAD** 检查对象存在、正数大小和保存的 `Content-Type` 元数据，不完整读取对象正文。实际大小必须等于最初申请凭证的声明，即使确认时填写另一大小也不能改写原声明；类型元数据须与凭证归一化后的 MIME 类型一致。只有属于当前用户、待确认且未过期的记录才能原子转为可用，重复或冲突确认不会替换已可用对象。普通上传中超过 100 MiB 的视频在确认时还会读取对象，核对完整保存大小和 MP4/MOV 容器；临时读取失败可以重试。容器检查**不代表**编码或可解码性已通过。这些元数据检查**不代表**真实媒体格式、时长或安全校验。普通上传仍适用独立的参考媒体准备检查；下文参考视频用途改为浏览器检查。

## 参考视频浏览器检查

参考视频浏览器检查上传用途已于 2026 年 10 月 18 日生效。创作页面在申请上传前，先在浏览器中读取并检查原始文件。检查失败或当前服务无法跟随参考时长、画幅时，通过系统既有的页面顶部消息气泡提示，不添加也不上传该文件。浏览器保留完整信息，生成时再次提交；时长和画幅跟随参考视频，不再由用户手动设置。

申请凭证的 JSON 正文新增以下可选字段。表单回退使用同名字段，但 `video_metadata` 必须是**经过 JSON 编码的字符串**，不能作为另一个文件项提交。

| 字段 | 申请凭证时的 JSON 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `purpose` | string | 否 | 仅在完整本地参考视频检查通过后使用固定值 `influencer_reference_video`；普通上传不传。 |
| `video_metadata` | object | 使用此用途时必填 | 直接提交下表中的浏览器实测字段，不加 `raw`、`version` 或 `browserMetadata` 外层。缺失或超出范围会被拒绝。这些是客户端声明，不是服务器已核验的媒体事实。 |

| `video_metadata` 字段 | 类型 | 说明 |
| --- | --- | --- |
| `duration` | number | 容器真实时长，单位秒；保留测得的小数。 |
| `video_duration` | number | 视频轨道真实时长，单位秒；保留测得的小数。 |
| `width` | integer | 考虑旋转后的实际显示宽度，单位像素。 |
| `height` | integer | 考虑旋转后的实际显示高度，单位像素。 |
| `frame_rate` | number | 测得的每秒视频帧数。 |
| `video_codec` | string | `h264` 或 `hevc`。 |
| `audio_codec` | string | 无音轨时为空；有音轨时为 `aac`、`mp3`，只有 MOV 还允许 `pcm`／`pcm_*`。 |
| `container` | string | 真实容器：`mp4` 或 `mov`。 |
| `size_bytes` | integer | 文件实际正整数字节数，必须与上传大小声明一致。 |

当前浏览器检查上传用途还要求以下规格声明。仅满足通用视频输入范围，不代表当前生成服务能够跟随原片。

| 声明规格 | 当前要求 |
| --- | --- |
| 容器及视频轨道时长 | 两者均在 4 至 30 秒之间。令 `s = round(duration)`，`s` 须为 4–30，两种实测时长与同一个 `s` 的差值都不能超过 `1 / frame_rate + 0.001` 秒。保留原始值，页面会显示实际生成的整秒时长；例如 7.2 秒会被拒绝，不会静默缩短。 |
| 宽度和高度 | 各为 300–6000 像素。 |
| 总像素数 | `width × height` 为 407696–8295044。 |
| 输入宽高比 | 0.4–2.5，并同时满足下方更严格的跟随画幅规则。 |
| 帧率 | 每秒 24–60 帧。 |
| 跟随原片画幅 | 此用途按当前 480p 画幅范围检查：`16:9`、`9:16` 或 `3:4`。对 `n:d`，仅当 `abs(width × d - height × n) ≤ (n + d) / 2` 时容忍整像素取整误差。页面还会检查所选成片清晰度；720p 当前仅支持 `16:9` 和 `9:16`。例如 `1:1` 原片虽然可能满足通用输入范围，但当前服务无法保留该画幅，因此此用途不接收。 |

应提供全部字段，数值必须有限。声明的媒体类型须与 `container` 一致：MP4 使用 `video/mp4`；MOV 使用 `video/quicktime` 或 `video/x-quicktime`。申请凭证的 `file_size` 必须等于 `video_metadata.size_bytes`；表单上传的文件项大小和 Content-Type 也须与这些声明一致。**200 MiB（209,715,200 字节）**硬上限仍保留。服务端检查声明的范围与一致性，但不会为此用途读取文件来确认媒体事实。

申请凭证成功时，服务器将该策略绑定到上传记录，保留专用目录 `influencer-reference/browser-upload`，忽略此用途下调用方填写的自定义目录。确认时不能将普通凭证改为此用途。直传确认仍检查归属、待确认状态、过期时间，以及 R2 HEAD 返回的对象存在性、准确大小和 Content-Type 一致性，超过 100 MiB 也一样；**不会**下载对象核验容器、编码、时长、分辨率或可解码性。表单回退仍需经过服务器传输字节，但此用途不检查媒体内容。该策略不会将元数据标记为“服务器已核验”，也不改变普通上传或公开视频生成接口的行为。

## 表单字段 (multipart/form-data)

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | binary | 是 | 文件二进制数据流 |
| `upload_path` | string | 否 | 自定义分类子目录（支持下划线或驼峰 `uploadPath`） |
| `file_name` | string | 否 | 自定义文件名（支持下划线或驼峰 `fileName`） |
| `purpose` | string | 否 | 使用 `influencer_reference_video`，见上文浏览器检查说明。 |
| `video_metadata` | JSON string | 使用此用途时必填 | 将完整原始信息对象编码为字符串提交。 |
