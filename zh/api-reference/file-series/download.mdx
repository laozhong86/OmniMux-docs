> - 公开寻址（免登录），依赖全局唯一的 `file_id` 访问
> - 支持 **302 重定向** 至公开对象存储；升级后的网关要求存储来源独立隔离
> - 通过网关输出文件时，自动设置正确的 `Content-Type` 与 `Content-Disposition`
> - 文件超出 **72 小时** 后自动失效并返回 `404 Not Found`

## 路径参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file_id` | string | 是 | 上传成功时返回的文件全局唯一标识（如 `file_8e6d425c0e564bde`） |

## 响应说明

- **未过期文件 (200 OK / 302 Found)**：返回文件二进制数据流或重定向至 R2 公共存储直链。
- **过期或已删除文件 (404 Not Found)**：
  ```json
  {
    "success": false,
    "code": 404,
    "msg": "文件已过期"
  }
  ```

## 升级后的上传内容隔离

以下为升级说明，相关保护在对应网关更新部署后适用；本文发布不代表正式服务已经部署。

仅当公开对象存储来源与应用及可信登录来源相互独立时，才保留存储直链重定向。同一主机即使使用不同协议或端口，仍不视为安全隔离。公开存储配置无效、主机重叠或无法确认隔离时，新上传会在写入存储前被拒绝。

既有文件通过网关访问时，无法安全重定向的文件由网关输出。网关响应带有浏览器沙箱策略，阻止网页和矢量图片中的脚本运行。文件字节、媒体类型、公开文件标识和过期规则不变。

请使用上传响应中的 `file_url` 或 `download_url`，不要自行拼接存储直链。既有不安全公开对象需要迁移到私有或独立存储，或在原始出口施加隔离；改写返回地址不能撤销旧的公开地址。
