> - 支持 Data URL 格式（如 `data:image/png;base64,...`）与纯 Base64 编码
> - 自动识别图片、音频、视频或通用文件 MIME 类型
> - 文件会在 **72 小时** 后自动过期并由后台服务物理清理
> - 单用户最多存储 **2,000** 个活跃文件，配额耗尽时会返回 429 提示
> - 鉴权：`Authorization: Bearer sk-...`

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `base64_data` | string | 是 | Base64 编码的数据或 Data URL 字符串 |
| `upload_path` | string | 否 | 自定义分类子目录（如 `avatars`、`covers`），不填时系统根据类型自动归类 |
| `file_name` | string | 否 | 自定义文件名（如 `avatar.png`），不填时自动生成唯一文件名 |

## 响应示例

```json
{
  "success": true,
  "code": 200,
  "msg": "文件上传成功",
  "data": {
    "file_id": "file_8e6d425c0e564bde",
    "file_name": "avatar.png",
    "original_name": "avatar.png",
    "file_size": 2048,
    "mime_type": "image/png",
    "upload_path": "avatars",
    "file_url": "https://api.omnimux.ai/api/v1/files/download/file_8e6d425c0e564bde",
    "download_url": "https://api.omnimux.ai/api/v1/files/download/file_8e6d425c0e564bde",
    "upload_time": "2026-09-10T23:49:40+08:00",
    "expires_at": "2026-09-13T23:49:40+08:00"
  }
}
```

## 使用返回的文件地址

请使用**响应**中的 `file_url` 或 `download_url` 访问上传文件，不要自行拼接存储地址。升级要求见[下载隔离说明](/zh/api-reference/file-series/download#升级后的上传内容隔离)。隔离更新部署后，不安全或无法确认隔离的公开存储配置会在写入文件前拒绝上传。

## 升级后的请求大小限制

以下限制在上传请求限制更新部署后生效；文档发布不代表正式网关已经部署。1 MiB = 1,048,576 字节。文件上限仍为 **100 MiB**。网关或代理设置的更严格限制仍优先生效，尤其是 `/v1/files/upload/` 别名现有的全局限制，可能在大体积 Base64 请求达到此处上限前拒绝请求。

JSON 请求预算为 **140,858,712 字节**：100 MiB 文件的标准 Base64 编码长度，再加 1 MiB 的 JSON 元数据及编码开销。解码后的文件不得超过 100 MiB。声明的请求体超限、解析时读取的内容超限，或解码后文件超限，均返回 **HTTP 413**；JSON 格式错误或 Base64 无效仍返回 **HTTP 400**。
