> - 提供公网公开可访问的 HTTP/HTTPS 文件链接，服务端自动下载并存储
> - 内置严格私网拦截与 SSRF 安全防护
> - 文件会在 **72 小时** 后自动过期并由后台服务物理清理
> - 单用户最多存储 **2,000** 个活跃文件，配额耗尽时会返回 429 提示
> - 鉴权：`Authorization: Bearer sk-...`

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file_url` | string | 是 | 远程文件的公网可访问 HTTP/HTTPS 链接 |
| `upload_path` | string | 否 | 自定义分类子目录，不填时系统根据类型自动归类 |
| `file_name` | string | 否 | 自定义文件名，不填时从 URL 路径解析或自动生成 |

## 响应示例

```json
{
  "success": true,
  "code": 200,
  "msg": "文件上传成功",
  "data": {
    "file_id": "file_c92cffd62415447d",
    "file_name": "image.jpg",
    "original_name": "image.jpg",
    "file_size": 17129,
    "mime_type": "image/jpeg",
    "upload_path": "downloads",
    "file_url": "https://api.omnimux.ai/api/v1/files/download/file_c92cffd62415447d",
    "download_url": "https://api.omnimux.ai/api/v1/files/download/file_c92cffd62415447d",
    "upload_time": "2026-09-10T23:50:07+08:00",
    "expires_at": "2026-09-13T23:50:07+08:00"
  }
}
```

## 使用返回的文件地址

请使用**响应**中的 `file_url` 或 `download_url` 访问上传文件，不要自行拼接存储地址。升级要求见[下载隔离说明](/zh/api-reference/file-series/download#升级后的上传内容隔离)。隔离更新部署后，不安全或无法确认隔离的公开存储配置会在写入文件前拒绝上传。

## 升级后的请求大小限制

以下限制在上传请求限制更新部署后生效；文档发布不代表正式网关已经部署。1 MiB = 1,048,576 字节。文件上限仍为 **100 MiB**。网关或代理设置的更严格限制仍优先生效，尤其是 `/v1/files/upload/` 别名现有的全局限制，可能在大体积 Base64 请求达到此处上限前拒绝请求。

包含链接和元数据的 JSON 请求预算为 **1 MiB**。声明的请求体超限或解析时读取的内容超限，返回 **HTTP 413**。远程下载的文件仍不得超过 **100 MiB**，远程文件超限继续返回 **HTTP 400**；JSON 格式错误或链接无效也仍返回 **HTTP 400**。
