## 素材与结果

通过 `parts[].inlineData` 提交 PNG、MP4 或 PDF；`mimeType` 与实际文件一致，`data` 为不含数据网址前缀的完整文件编码。本页未列出的格式、素材容量和长素材限制，请在接入前确认，勿将请求示例当作服务上限。

使用低思考档时，设置 `generationConfig.thinkingConfig.thinkingLevel: low`。`maxOutputTokens` 同时覆盖思考与可见输出，示例值不代表最大输出上限。

需要结构化结果时，使用 `generationConfig.responseMimeType: application/json` 与原生 `responseSchema`。这些结构化输出参数会按原生请求转发，但返回内容仍可能带有代码围栏，或出现不符合结构要求的字段类型，例如预期数组的字段返回为对象。调用方须校验实际返回内容和字段类型，再用于后续处理。

检查完整回复的 `finishReason`、返回内容及 `usageMetadata`。收到 `functionCall` 后，由调用方执行函数；本页不承诺多轮工具执行。

## 费用与用量

按已公布的账户价格和实际用量结算；自动切换服务线路不会改变该模型的已公布售价。普通输入包含上游已报告的工具输入，输出包含已报告的思考；已报告缓存属于输入子集，不再重复累加。流式累计快照也不按片段重复计费。缺失的用量字段不代表上游明确报告零。

余额不足应检查错误体：除 `402` 外，原生入口也可能返回 `403` 和 `insufficient_user_quota`；不要将全部 `403` 都归为权限问题。
