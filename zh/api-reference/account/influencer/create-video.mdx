使用 `character_task_id` 加可选有序补充 `image_urls`，或直接用图片且第一张为主要角色。总数不超过 30 张。参考视频来源必须二选一：`video_url` 或本人成功的 `video_task_id`。

- 服务地址为 `https://omnimux.ai`，使用限定权限个人凭据，不使用 `sk-` 网关密钥。
- 所需权限：`influencer_creation:write`.
- `New-Api-User` 只作可选兼容信息。账号由凭据确定，此请求头不能选择其他归属。

新增权限须重新明确完成设备授权；已有和旧式凭据不会自动扩权。见[设备码登录](/zh/api-reference/account/device-login)。

<Note>
200 代表已持久受理排队或恢复，不代表成片或扣费确认。生成沿用账号积分/订阅额度。原生执行阶段对额度不足采用需要额度（402）的语义，但此受理入口不会同步返回 402；排队后仍可能失败。请查询任务状态和公开失败原因；不承诺视频生成前的精确报价。
</Note>

未知顶层请求字段返回 400。不要传入 `model`、`group`、`seed`、`size` 或手填时长。使用同一账号的相同 `request_id` 与内容恢复原任务；改内容返回 409，恢复过期返回 410。生成开关关闭时新请求返回 503 `influencer_creation_disabled`，已受理请求的原样恢复和本人读取仍可使用。

后台在受理生成前识别真实时长（4–30 秒）、画幅、帧率、尺寸、编码及声音。支持 MP4/MOV、H.264/HEVC；24–60 帧/秒；每边 300–6000 像素；总像素 407696–8295044；来源宽高比 0.4–2.5。不合格素材直接拒绝，不悄悄裁剪或补时。

| 清晰度 | 支持的输出画幅 |
| --- | --- |
| `480p` | `16:9`, `9:16`, `3:4` |
| `720p` | `16:9`, `9:16` |

默认 `motion`、`480p`。动作迁移明确画幅优先；省略时使用受支持的来源画幅，否则 `9:16`。对象交换保持受支持的来源画幅，冲突时拒绝。

请求保留图片顺序、传入参考原声，并沿用已存角色的人物/猫/狗类型。成片仍须核对外观、动作、画面和声音，任务成功本身不代表创作效果验收通过。

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://omnimux.ai/api/influencer/v1/videos' \
  --header 'Authorization: Bearer <user-access-token>' \
  --header 'Content-Type: application/json' \
  --data '{"request_id":"creator-video-0001","character_task_id":"task_example_character","video_url":"https://omnimux.ai/REPLACE_WITH_OWN_REFERENCE.mp4","mode":"motion","resolution":"480p"}'
```
