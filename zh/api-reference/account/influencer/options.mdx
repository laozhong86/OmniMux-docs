<Note>
本组页面说明账号 HTTP 接口。配套的新命令已经在项目源码实现，但公开的 0.4.4 安装版尚不包含这些命令。本次文档不宣告新的命令行发行版本。
</Note>


读取当前角色选项、默认值、素材限制和支持的清晰度与画幅组合。同时检查 `creation_enabled` 与对应的 `availability` 或清晰度 `available` 值，不提供供应商或模型选择。

- 服务地址为 `https://omnimux.ai`，使用限定权限个人凭据，不使用 `sk-` 网关密钥。
- 所需权限：`influencer_creation:read`.
- `New-Api-User` 只作可选兼容信息。账号由凭据确定，此请求头不能选择其他归属。

新增权限须重新明确完成设备授权；已有和旧式凭据不会自动扩权。见[设备码登录](/zh/api-reference/account/device-login)。

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://omnimux.ai/api/influencer/v1/options' \
  --header 'Authorization: Bearer <user-access-token>'
```
