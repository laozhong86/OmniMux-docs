返回与任务详情相同的安全任务数据，包含 `artifacts` 数组，不直接返回文件内容。只有成功且有可用成品时才显示 `artifact_status: ready`。签名下载地址过期时重新查询此入口。

- 服务地址为 `https://omnimux.ai`，使用限定权限个人凭据，不使用 `sk-` 网关密钥。
- 所需权限：`influencer_creation:read`.
- `New-Api-User` 只作可选兼容信息。账号由凭据确定，此请求头不能选择其他归属。

新增权限须重新明确完成设备授权；已有和旧式凭据不会自动扩权。见[设备码登录](/zh/api-reference/account/device-login)。

查询接口时使用账号凭据，下载签名 `content_url` 时不向成品地址或重定向目标转发账号凭据。不要记录签名地址。确认完整且非空文件后才报告下载成功；地址过期不能成为重新生成的理由。
