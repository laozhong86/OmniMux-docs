默认 `normal` 为普通人物，其他类型为 `freak`、`total`、`cats`、`dogs`。人物类型至少提供有效特征、描述或风格参考图之一。角色主图保留固定的 16:9 双视图构图。

角色主图是一张 1920x1088 的 PNG，包含两个视图。最终拼装的完整提示词还须满足[标准图片服务限制](/zh/api-reference/image-series/gpt-image/generate)：8192 个 Unicode 码点、16384 个 UTF-8 字节，以及本服务计数的 5000 个词元。描述不超过 4000 字符，并不保证拼装后一定符合提交条件。超限时明确失败，不截断或替换输入。

- 服务地址为 `https://omnimux.ai`，使用限定权限个人凭据，不使用 `sk-` 网关密钥。
- 所需权限：`influencer_creation:write`.
- `New-Api-User` 只作可选兼容信息。账号由凭据确定，此请求头不能选择其他归属。

新增权限须重新明确完成设备授权；已有和旧式凭据不会自动扩权。见[设备码登录](/zh/api-reference/account/device-login)。

<Note>
200 代表已持久受理排队或恢复，不代表成片或扣费确认。生成沿用账号积分/订阅额度。原生执行阶段对额度不足采用需要额度（402）的语义，但此受理入口不会同步返回 402；排队后仍可能失败。请查询任务状态和公开失败原因；不承诺视频生成前的精确报价。
</Note>

未知顶层请求字段返回 400。不要传入 `model`、`group`、`seed`、`size` 或手填时长。使用同一账号的相同 `request_id` 与内容恢复原任务；改内容返回 409，恢复过期返回 410。生成开关关闭时新请求返回 503 `influencer_creation_disabled`，已受理请求的原样恢复和本人读取仍可使用。

`selection` 是 `{"gender":["female"]}` 这样的对象，不是数组。请从[创作选项](/zh/api-reference/account/influencer/options)读取当前编号及可见性。可选风格图支持 JPEG、PNG、WebP，最多 5 MiB。
