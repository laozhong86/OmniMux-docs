openapi: "openapi/ops/influencer/zh/creation.json GET /api/influencer/v1/tasks/{task_id}"
---

自动处理使用归一化 `status`，成品是否可用看 `artifact_status`。单独的 `succeeded` 不保证有可用文件。任务失败或 `quota_status: reconciling` 不代表积分已经退回。

`artifacts` 中的视频项可包含可选的 `video_metadata` 对象，字段与限制见[查询创作成品](/zh/api-reference/account/influencer/get-artifacts)；历史任务和非视频成品不包含。

- 服务地址为 `https://omnimux.ai`，使用限定权限个人凭据，不使用 `sk-` 网关密钥。
- 所需权限：`influencer_creation:read`.
- `New-Api-User` 只作可选兼容信息。账号由凭据确定，此请求头不能选择其他归属。

新增权限须重新明确完成设备授权；已有和旧式凭据不会自动扩权。见[设备码登录](/zh/api-reference/account/device-login)。

状态包括 `waiting`、`submitting`、`queued`、`running`、`succeeded`、`failed`；`reconciling` 表示提交结果待核对，不能自动另开任务。停止本地等待或撤销凭据不会取消已受理任务。
