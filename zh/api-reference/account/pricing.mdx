- 公开目录接口，无需鉴权。
- 每个在售模型行都带 `contract` 对象：包含模型级能力包络，以及 Contract v2 起提供的可执行操作列表。

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 账户管理 |
| 能力 | 公开定价 |

## 接口

| 方法 | 路径 |
| --- | --- |
| `GET` | `/api/pricing` |

Base URL：`https://omnimux.ai`

## 响应

### 200

`data` 是模型数组。每行包含 `model_name`、`quota_type`、`model_ratio`、`model_price`、`enable_groups` 和 `contract`。

可选的顶层 `defaults` 按操作推荐模型（`chat`、`vision_chat`、`text_to_image`、`text_to_video`、`text_to_music`、`speech_to_text`）。每个值都指向同一响应中 `enable_groups` 非空的模型；没有可用推荐时省略对应键。

`contract` 是纯描述数据，不参与计费、额度或结算。

| 契约字段 | 含义 |
| --- | --- |
| `schemaVersion` | 契约形态。`"2.0"` 表示 `operations` 是对象数组。 |
| `contractVersion` | 每个模型独立的内容哈希；客户端可据此只缓存/刷新变化的模型。 |
| `operations[]` | 可执行操作。每项含 `id`、`executable`、`inputs[]`、`parameters[]`、`output.type`。 |
| `operation_ids[]` | 同一批操作 ID 的字符串数组，兼容 v1 客户端。 |
| `unknowns[]` | 治理档案未建立的字段路径；缺失字段不是默认值。 |
| `reference_images` / `reference_videos` / `reference_audios` | 参考素材数量、格式与大小上限。 |
| `reasoning_efforts` | 可选：文本模型的推理档位到上游 wire value 的映射。 |
| `default_reasoning_effort` | 可选：默认推理档位；存在时必须是 `reasoning_efforts` 的键。 |

操作输入项包含 `slot`、`type`、`role`、`required`、`min`、`max`、`allowedMimes`、`maxSizeMb` 及已声明的时长边界。参数项包含 `name`、`type`、`enum`、`minimum`、`maximum`、`step`、`default`、`fixed`、`limitSource`。

`executable: false` 表示厂商文档列出了该操作，但本网关不支持执行；客户端不得提交。

## 相关接口

`GET /api/model_contract/:model` 返回单个模型的完整 v2 契约（`data.contract`）与文档版本（`data.version`）。模型没有治理档案时返回 `404`——缺失表示“未建立”，不是“不存在该能力”。
