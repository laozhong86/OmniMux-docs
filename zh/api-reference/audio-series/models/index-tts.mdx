- 创建：`POST /v1/video/generations`，`model` 为 `index-tts`
- 轮询：`GET /v1/video/generations/{task_id}`（**不要**使用 `*-async` / `*-query` 模型名）
- GxgenAI 任务共用这条路径，即使产物是音频
- 必须传 `metadata.nodeInfoList`（参考音 + 文稿）
- 参考音先用公网 URL 或上游 fileName；不要传 `data:` URI
- 产物 URL 请及时落盘

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 音频系列 |
| 品牌 | Index TTS / GxgenAI |
| model | `index-tts` |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `index-tts` |
| `prompt` | string | 否 | 仅作标签；文稿写在节点 `7` |
| `metadata.nodeInfoList` | array | **是** | 参考音 + 文稿 |

必填节点：

| nodeId | fieldName | 含义 |
| --- | --- | --- |
| `4` | `audio` | 克隆参考音（自动截取前约 15 秒） |
| `7` | `text` | 要朗读的文字 |

## 响应

### 200（创建）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` / `task_id` | string | 任务 id |
| `status` | string | `queued` / `in_progress` / `completed` |

轮询见 [查询视频任务](/zh/api-reference/tasks/video-task)。错误见 [错误码](/zh/faqs/connection-usage)。
