所有目标账号必须属于请求来源。幂等命中也校验已存来源与账号集合；不符返回 409。

媒体先调用[媒体预签名](/zh/api-reference/publishing/presign)取得上传票据，把返回的 `public_url` 作为 `media` 引用；上传失败或对象不可读时不要提交帖子。

TikTok 按账号已授权的能力执行：

| 账号能力 | 行为 |
| --- | --- |
| `video.upload`（当前已批准） | **草稿上传**：视频进入创作者 TikTok 收件箱，用户在 TikTok 内完成编辑与发布。仅支持单条视频；`content` 与 `tiktok_options` 不生效 |
| `video.publish`（需另行审核） | **直接发布**：按 `tiktok_options` 的隐私与互动设置提交；支持视频与图文 |

账号缺少发布 scope 时返回 409 `SOCIAL_TIKTOK_SCOPE_MISSING`。草稿模式的状态先为 `processing`（含 `SEND_TO_USER_INBOX`），用户完成发布后为 `published`。

`provider` 必填，当前唯一取值 `tiktok_direct`。已退役的来源标识返回 410 `provider-retired`，缺失或未知值返回 400 `invalid-provider`。

使用 OmniMux 用户 access token 和 `New-Api-User`，不是 `sk-` 密钥。同时检查 HTTP 状态和 `success`；部分上游错误仍返回 HTTP 200、`success:false`。
