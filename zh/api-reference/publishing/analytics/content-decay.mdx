- 社媒 **发布** 用户 API（非 `sk-` 社交数据读）
- Base：`https://omnimux.ai`；鉴权 access token + `New-Api-User`
- 分析内容发布后不同时间窗口内的互动累积百分比分布与半衰期

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 社媒发布 |
| 资源组 | 社媒分析 |
| 能力 | 内容衰减曲线 |

## 接口

| 方法 | 路径 |
| --- | --- |
| `GET` | `/api/social/v1/analytics/content-decay` |

Base URL：`https://omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer <access_token>`（用户 access token） |
| `New-Api-User` | header | string | 是 | 当前用户 id |

## 查询参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `platform` | string | 否 | 平台过滤（`tiktok`、`x`、`instagram`、`youtube` 等） |

## 响应

### 200

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 是否成功 |
| `data.buckets` | array | 时间窗口互动累积分布 |
| `data.buckets[].bucketOrder` | integer | 序号（0-5） |
| `data.buckets[].bucketLabel` | string | 窗口标签（`0-6h`、`6-12h`、`12-24h`、`1-2d`、`2-7d`、`7-30d`） |
| `data.buckets[].avgPctOfFinal` | number | 平均达到最终总互动的百分比（%） |
| `data.buckets[].postCount` | integer | 样本帖子数 |
| `data.milestones` | object | 互动里程碑（50% 互动半衰期窗口与 80% 饱和窗口） |

错误见右栏与 [错误码](/zh/faqs/connection-usage)。
