- 社媒 **发布** 用户 API（非 `sk-` 社交数据读）
- Base：`https://omnimux.ai`；鉴权 access token + `New-Api-User`
- 统计每周发帖节奏与互动率的关联分布，寻找最佳内容产出频次

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 社媒发布 |
| 资源组 | 社媒分析 |
| 能力 | 发帖频次模型 |

## 接口

| 方法 | 路径 |
| --- | --- |
| `GET` | `/api/social/v1/analytics/posting-frequency` |

Base URL：`https://omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer <access_token>`（用户 access token） |
| `New-Api-User` | header | string | 是 | 当前用户 id |

## 查询参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `platform` | string | 否 | 平台过滤（`tiktok`、`x`、`instagram`、`youtube` 等） |

## 响应

### 200

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `success` | boolean | 是否成功 |
| `data.frequency` | array | 频次区间分析结果 |
| `data.frequency[].platform` | string | 平台名称 |
| `data.frequency[].postsPerWeek` | string | 每周发帖区间（如 `1-3/wk`、`6-10/wk`、`11+/wk`） |
| `data.frequency[].avgEngagementRate` | number | 平均互动率（%） |
| `data.frequency[].avgEngagement` | number | 平均互动数值 |
| `data.frequency[].weeksCount` | integer | 该区间样本周数 |
| `data.optimalCadence` | object | 各平台最优频次策略建议 |

错误见右栏与 [错误码](/zh/faqs/connection-usage)。
