为发布媒体申请一次性上传票据。票据签名到网关自有对象存储，不经过第三方存储；上传完成后把返回的 `public_url` 作为帖子的 `media` 引用。

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 社媒发布 |
| 资源组 | 媒体 |
| 能力 | 申请上传 |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/api/social/v1/media/presign` |

Base URL：`https://omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer <access_token>`（用户 access token） |
| `New-Api-User` | header | string | 是 | 当前用户 id |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `filename` | string | 是 | 原始文件名；服务端只取扩展名参与对象键 |
| `content_type` | string | 是 | MIME 类型；也接受 `contentType` |
| `size_bytes` | integer | 否 | 单文件上限校验，默认 512 MiB |

对象键由服务端生成，客户端不能指定。

## 响应 200

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `upload_url` | string | 直接 `PUT` 的目标地址 |
| `upload_method` | string | 通常为 `PUT` |
| `headers` | object | 上传时必须原样带上的请求头（含 `Content-Type`） |
| `public_url` | string | 平台可读地址，作为帖子的 `media` 引用 |
| `key` | string | 服务端生成的对象键 |
| `expires_in` | integer | 票据剩余秒数 |
| `filename` / `content_type` | string | 回显的请求值 |

## 上传

拿到票据后直接上传到 `upload_url`，不要再附带网关鉴权头：

```bash
curl --request PUT --upload-file ./clip.mp4 \
  --header 'Content-Type: video/mp4' \
  '<upload_url>'
```

上传失败、票据过期或对象不可读时不要提交帖子；重新申请票据即可。
