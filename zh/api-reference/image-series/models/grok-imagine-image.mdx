- 调用 `POST /v1/images/generations` 生成图像（`model` 设为 `grok-imagine-image`）；图像编辑请调用 `POST /v1/images/edits`
- 兼容 OpenAI 参数 `aspect_ratio`（未传 `size` 时自动映射为 `size`）以及 `response_format`（`url` 或 `b64_json`）
- 实时模型状态与定价请以[OmniMux 控制台](https://omnimux.ai/dashboard)或 `GET /v1/models` 为准；如需高质量档位，请查看 [Grok Imagine Image Quality 生图](/zh/api-reference/image-series/models/grok-imagine-image-quality)
- 若上游以异步方式执行，请记录创建响应中的 `task_id` / `id` 并在控制台用量日志中查看结果

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 图像系列 |
| 品牌 | Grok Imagine |
| model | `grok-imagine-image` |

## 型号对比

| 模型 ID | 定位 | 端点 | 文档 |
| --- | --- | --- | --- |
| `grok-imagine-image` | 标准版 | `POST /v1/images/generations` · `/v1/images/edits` | 本页 |
| `grok-imagine-image-quality` | 高质量档位 | `POST /v1/images/generations` · `/v1/images/edits` | [Grok Imagine Image Quality 生图](/zh/api-reference/image-series/models/grok-imagine-image-quality) |
| `grok-imagine-image-2-0` | 2.0 版本 | `POST /v1/images/generations` · `/v1/images/edits` | [Grok Imagine Image 2.0 生图](/zh/api-reference/image-series/models/grok-imagine-image-2-0) |

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | 文生图或带参考图生成 |
| `POST` | `/v1/images/edits` | 图像编辑（必须提供至少一张参考图） |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `grok-imagine-image` |
| `prompt` | string | 是 | 图像描述或编辑指令 |
| `n` | integer | 否 | 生成张数（受网关上限约束） |
| `size` | string | 否 | 尺寸或宽高比（模型相关） |
| `aspect_ratio` | string | 否 | 宽高比；未显式传入 `size` 时网关自动映射到 `size` |
| `response_format` | string | 否 | 返回格式：`url` 或 `b64_json` |
| `quality` | string | 否 | 质量档位（模型相关） |
| `images` | string[] | 条件 | 参考图 URL 或 base64 数组（调用 `POST /v1/images/edits` 时必填）；`image`、`image_urls`、`input_reference` 为可接受别名，转发前统一归一为 `images` |

### 参考图限制

本模型尚无正式模型规格档案，参考图最大张数、接受格式与单文件大小上限**未核验**：此处不作具体数值承诺。

## 响应

### 200

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `created` | integer | 创建时间戳（同步响应时返回） |
| `data` | array | 图像结果对象（含 `url` 或 `b64_json` 及可选 `revised_prompt`） |
| `task_id` / `id` | string | 异步任务 id（当上游以异步任务执行时返回） |

错误形态见右栏示例与[错误码说明](/zh/faqs/connection-usage)。异步任务以创建响应中的 `task_id` / 控制台日志为准（公开文档不提供独立图像查询路径）。

<RequestExample>

```bash cURL (文生图 · aspect_ratio 与 b64_json)
curl --request POST \
  --url https://api.omnimux.ai/v1/images/generations \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "grok-imagine-image",
  "prompt": "a product photo on white background",
  "aspect_ratio": "16:9",
  "response_format": "b64_json",
  "n": 1
}'
```

```bash cURL (图像编辑 /v1/images/edits)
curl --request POST \
  --url https://api.omnimux.ai/v1/images/edits \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "grok-imagine-image",
  "prompt": "change the studio backdrop to warm morning sunlight",
  "images": ["https://example.com/product.jpg"],
  "aspect_ratio": "1:1"
}'
```

</RequestExample>
