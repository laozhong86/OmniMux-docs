将一张已有图片的宽与高各放大至原来的两倍，无需提示词。仅提供 API 接入。

## 规格约束

| 项目 | 规范 |
| --- | --- |
| 模型标识 | `volc-image-upscale` |
| 输入来源 | 输入为一张免鉴权的公网 HTTPS 图片 URL。OmniMux API 请求仍需鉴权。 |
| 支持格式 | 支持 JPG、JPEG、PNG、BMP 图片。 |
| 文件大小 | 文件大小不超过 5 MB。 |
| 输入尺寸 | 输入图片宽度为 50 至 2128 像素，高度为 50 至 4064 像素，均含边界。 |
| 放大倍率 | 仅支持固定两倍超分，不支持文生图、遮罩、多图或自定义输出尺寸。 |
| 结果有效期 | 上游结果 URL 有效期为 24 小时，不保证永久可访问。 |

## 计费说明

- 官方刊例价格：0.006 元/次。
- 计费模式：固定按次计费（UsePrice）。
- 结算保护：上游服务异常、超时或返回空结果时，预扣额度将 100% 自动退回。
