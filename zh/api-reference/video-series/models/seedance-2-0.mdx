- 创建：`POST /v1/video/generations`，`model` 设为 `seedance-2-0`
- 异步任务：用返回的 `task_id` 查询 [查询视频任务](/zh/api-reference/tasks/video-task)
- 支持 `480p`、`720p`、`1080p` 与 `4k` 分辨率、`4–30` 秒时长、可选同步音频、首帧/首尾帧及多模态参考生视频
- 最新定价请以[OmniMux 控制台](https://omnimux.ai/dashboard)或 `GET /v1/models` 为准；另见 [Seedance 2.0 Fast](/zh/api-reference/video-series/models/seedance-2-0-fast) 与 [Seedance 2.5](/zh/api-reference/video-series/models/seedance-2-5)
- 产物 URL 请及时落盘（上游链接可能有时效）

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 视频系列 |
| 品牌 | Seedance |
| model | `seedance-2-0` |

## 支持模式

| 模式 (`operation`) | 输入要求 | 画面比例 |
| --- | --- | --- |
| `text_to_video` | `prompt` | `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` |
| `first_frame` | `prompt` + `image_with_roles`（`role: "first"`） | 固定为 `adaptive` |
| `first_last_frame` | `prompt` + `image_with_roles`（`role: "first"` 与 `"last"`） | 固定为 `adaptive` |
| `video_multi_ref` | `prompt` + `image_urls` / `video_urls` / `audio_urls` | `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`（最多 9 图、3 视频、3 音频） |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `seedance-2-0` |
| `prompt` | string | 是 | 视频生成描述提示词 |
| `duration` / `seconds` | integer | 否 | 视频时长（秒，支持 `4` 至 `30`） |
| `resolution` | string | 否 | 分辨率：`480p`、`720p`、`1080p` 或 `4k` |
| `aspect_ratio` / `size` | string | 否 | 画面比例：`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`（`first_frame` 与 `first_last_frame` 固定 `adaptive`） |
| `generate_audio` | boolean | 否 | 是否生成同步音频，默认 `false` |
| `image_with_roles` | array | 否 | 首帧/首尾帧角色图数组（`role: "first"` / `"last"`） |
| `image_urls` | array | 否 | 多模态参考图片 URL（最多 9 张） |
| `video_urls` | array | 否 | 多模态参考视频 URL（最多 3 段） |
| `audio_urls` | array | 否 | 多模态参考音频 URL（最多 3 段） |

## 响应

### 200（创建）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 id，用于轮询 |
| `status` | string | 如 `queued` / `processing` / `completed` |

轮询字段见 [查询视频任务](/zh/api-reference/tasks/video-task)。错误见右栏与 [错误码](/zh/faqs/connection-usage)。
