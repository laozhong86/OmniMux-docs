- 创建：`POST /v1/video/generations`，`model` 设为 `wan-3.0`
- 异步任务：用返回的 `task_id` 查询 [查询视频任务](/zh/api-reference/tasks/video-task)
- 只有一个公开 ID；档位由请求的分辨率决定（分辨率必填），调用方不选分组
- 支持 `text_to_video`、`first_frame`、`first_last_frame`、`video_multi_ref`、`document_to_video`（`file_url`）与 `webpage_to_video`（`link_url`），并支持可选 `generate_audio`（默认 `false`）
- 产物 URL 请及时落盘（上游链接可能有时效）

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 视频系列 |
| 品牌 | Wan |
| model | `wan-3.0` |
| 计费量纲 | 按秒（per second） |

## 支持模式

| 模式 (`operation`) | 输入要求 | 画面比例与约束 |
| --- | --- | --- |
| `text_to_video` | `prompt` | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive` |
| `first_frame` | `prompt` + `image_with_roles`（`role: "first"`） | 固定为 `adaptive`（单图 `<= 20 MB`，支持 JPEG/PNG/BMP/WebP） |
| `first_last_frame` | `prompt` + `image_with_roles`（`role: "first"` 与 `"last"`） | 固定为 `adaptive`（单图 `<= 20 MB`，支持 JPEG/PNG/BMP/WebP） |
| `video_multi_ref` | `prompt` + `image_urls` / `video_urls` / `audio_urls` | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive`（最多 `10` 图单张 `<= 20 MB`、`5` 视频单段 `<= 100 MB`、`5` 音频单段 `<= 15 MB`） |
| `document_to_video` | `prompt` + `file_url` | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive`（公开文档 URL；与媒体数组及 `link_url` 互斥） |
| `webpage_to_video` | `prompt` + `link_url` | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive`（公开 HTTP/HTTPS 网页 URL；与媒体数组及 `file_url` 互斥） |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL：`https://api.omnimux.ai`

| 名称 | 位置 | 类型 | 必填 | 说明 |

## 分辨率即档位

`wan-3.0` 只有一个公开模型 ID，档位不通过模型 ID 选择：网关按请求里的分辨率自动选组，调用方不需要、也不必自己选分组。

| 档位 | 分组 | 分辨率 | 价格（人民币/秒） |
| --- | --- | --- | --- |
| 720p 档 | `wan-3.0-720p` | `720p` | **¥0.60/秒** |
| 1080p 档 | `wan-3.0-1080p` | `1080p` | **¥1.80/秒** |

- 分辨率必须显式传：档位决定渠道，未传分辨率且未显式指定分组时没有可用渠道，请求会被拒绝（`400`）。
- 分辨率写法：`720p` / `1080p`（大小写不敏感），也可用等价尺寸写法，如 `1280x720`、`1920x1080`；尺寸按较短边归入档位，横版与竖版同价。
- 只提供 `720p` 与 `1080p` 两档；其它分辨率会被拒绝（`400`），错误消息会列出可用取值。
- 计费量纲为按秒（per second），对外报价以人民币计。
- `POST /v1/video/generations` 与控制台内的 `POST /pg/video/generations` 都会自动选组；后者只接受浏览器登录态，不属于令牌 API 面。
- 显式选择优先：请求头 `X-Omnimux-Group`、请求体 `group`、或 `model@分组` 后缀由调用方指定时，以显式分组为准，自动选组不会覆盖。

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `wan-3.0`，可带 `@分组` 后缀 |
| `prompt` | string | 条件 | 文生视频时必填 |
| `duration` | integer | 否 | 时长（秒），已发布包络 4–30；带参考视频时上限更低（≤ 15 秒） |
| `seconds` | string | 否 | 时长的 OpenAI 原生写法，**必须传字符串**（如 `"5"`）；传数字会在任何插件之前被拒（`400`） |
| `resolution` / `size` | string | 是 | `720p` 或 `1080p`（或等价尺寸），决定档位、渠道与价格 |
| `aspect_ratio` | string | 否 | 画面比例：`16:9`、`4:3`、`1:1`、`3:4`、`9:16` 或 `adaptive`（`first_frame` 与 `first_last_frame` 固定 `adaptive`） |
| `generate_audio` | boolean | 否 | 是否生成同步音频，默认 `false` |
| `image_with_roles` | array | 否 | 首帧/首尾帧角色图数组（`role: "first"` / `"last"` 或 `"first_frame"` / `"last_frame"`；JPEG/PNG/BMP/WebP `<= 20 MB`） |
| `image_urls` | array | 否 | 多模态参考图片 URL（最多 `10` 张，JPEG/PNG/BMP/WebP `<= 20 MB`） |
| `video_urls` | array | 否 | 多模态参考视频 URL（最多 `5` 段，MP4/QuickTime `<= 100 MB`；携带参考视频时时长上限为 `<= 15` 秒） |
| `audio_urls` | array | 否 | 多模态参考音频 URL（最多 `5` 段，WAV/MP3 `<= 15 MB`） |
| `file_url` | string | 否 | `document_to_video` 使用的公开 HTTP/HTTPS 文档 URL（支持 `.pdf`、`.docx`、`.pptx`、`.xlsx`、`.txt`、`.md`、`.key`、`.pages`、`.numbers`） |
| `link_url` | string | 否 | `webpage_to_video` 使用的公开 HTTP/HTTPS 网页 URL（与 `file_url` 及媒体数组互斥） |

- 时长低于 4 秒或高于 30 秒不受理；带参考视频的请求上限为 15 秒。
- `duration` 与 `seconds` 二选一即可，都表示时长：`duration` 传整数（`5`），`seconds` 传字符串（`"5"`）。
- 未传分辨率且未显式指定分组时没有可用渠道，请求会被拒绝（`400`），不会被静默计价到其它档位。

## 计费

- 按请求的视频时长计费，单位为人民币/秒：
  - `720p` 档：**¥0.60/秒**
  - `1080p` 档：**¥1.80/秒**
- 基准锚官方 1080P 原价 **¥1.20/秒**；720p 档为 0.5 倍、1080p 档为 1.5 倍。
- 例：`720p` / 5 秒 = ¥3.00；`1080p` / 5 秒 = ¥9.00。
- 最终价格以公开定价接口与提交前报价为准。
