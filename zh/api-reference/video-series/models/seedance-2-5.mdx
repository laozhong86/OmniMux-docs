- 创建：`POST /v1/video/generations`，`model` 可选 `seedance-2-5`（标准通道）或 `seedance-2-5-task`（按次任务固定计费通道）
- 异步任务：用返回的 `task_id` 查询 [查询视频任务](/zh/api-reference/tasks/video-task)
- 支持 `480p`、`720p` 与 `1080p` 分辨率、`4–30` 秒时长（`video_edit` 固定 `-1` 自动时长）、`mp4` / `mov` 输出格式、可选 `generate_audio`（默认 `false`），覆盖 `text_to_video`、`first_frame`、`first_last_frame`、`video_multi_ref`、`video_edit` 与 `video_extend` 6 种模式
- 最新定价请以[OmniMux 控制台](https://omnimux.ai/dashboard)或 `GET /v1/models` 为准；另见 [Seedance 2.5 Flash](/zh/api-reference/video-series/models/seedance-2-5-flash)
- 产物 URL 请及时落盘（上游链接可能有时效）

<Note>
角色工作台的参考视频有独立的[输入要求与编辑能力边界说明](/zh/faqs/features#角色工作台的参考视频检查)。这些检查与网站登录会话预检，不代表新增公开 `/v1` 接口或本接口的新参数；参考输入比例与生成输出比例须分别判断。
</Note>

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 视频系列 |
| 品牌 | ByteDance |
| model | `seedance-2-5`, `seedance-2-5-task` |

## 支持模式

| 模式 (`operation`) | 输入要求 | 画面比例与参数约束 |
| --- | --- | --- |
| `text_to_video` | `prompt` | `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive` |
| `first_frame` | `prompt` + `image_with_roles`（`role: "first"`） | 固定为 `adaptive`（单图 `<= 30 MB`） |
| `first_last_frame` | `prompt` + `image_with_roles`（`role: "first"` 与 `"last"`） | 固定为 `adaptive`（单图 `<= 30 MB`） |
| `video_multi_ref` | `prompt` + `image_urls` / `video_urls` / `audio_urls` | `21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`adaptive`（`1–30` 图单张 `<= 30 MB`、`0–10` 视频单段 `<= 200 MB`、`0–10` 音频单段 `<= 15 MB`） |
| `video_edit` | `prompt` + `video_urls`（1 段源视频） | 固定为 `adaptive`，`duration` 固定 `-1`（传入视频时须显式传 `operation: "video_edit"`） |
| `video_extend` | `prompt` + `video_urls`（1 段源视频） | 固定为 `adaptive`，`duration` 支持 `4–30` 秒（须显式传 `operation: "video_extend"`） |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | `seedance-2-5`（标准通道）或 `seedance-2-5-task`（按次任务固定计费通道） |
| `operation` | string | 条件 | 可选 `text_to_video`、`first_frame`、`first_last_frame`、`video_multi_ref`、`video_edit` 或 `video_extend`（传入 `video_urls` 时须显式指定） |
| `prompt` | string | 是 | 视频生成或编辑提示词 |
| `duration` / `seconds` | integer | 否 | 视频时长（秒，支持 `4` 至 `30`；`video_edit` 传参时固定为 `-1`） |
| `resolution` | string | 否 | 分辨率：`480p`、`720p` 或 `1080p` |
| `aspect_ratio` / `size` | string | 否 | 画面比例：`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` 或 `adaptive`（`first_frame`、`first_last_frame`、`video_edit`、`video_extend` 固定 `adaptive`） |
| `output_format` | string | 否 | 输出格式：`mp4` 或 `mov` |
| `generate_audio` | boolean | 否 | 是否生成同步音频，默认 `false` |
| `image_with_roles` | array | 否 | 首帧/首尾帧角色图数组（`role: "first"` / `"last"` 或 `"first_frame"` / `"last_frame"`） |
| `image_urls` | array | 否 | 多模态参考图片 URL（`1–30` 张，单张 `<= 30 MB`；支持 JPEG/PNG/WebP/BMP/TIFF/GIF/HEIC/HEIF） |
| `video_urls` | array | 否 | 多模态参考视频（`video_multi_ref` 最多 10 段）或 1 段源视频（`video_edit` / `video_extend`），MP4/QuickTime `<= 200 MB` |
| `audio_urls` | array | 否 | 多模态参考音频 URL（`0–10` 段，WAV/MP3，单段 `<= 15 MB`） |

## 响应

### 200（创建）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 id，用于轮询 |
| `status` | string | 如 `queued` / `processing` / `completed` |

轮询字段见 [查询视频任务](/zh/api-reference/tasks/video-task)。错误见右栏与 [错误码](/zh/faqs/connection-usage)。
