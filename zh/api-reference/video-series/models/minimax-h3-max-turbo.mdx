- 创建：`POST /v1/video/generations`，`model` 为 `minimax/h3-max-turbo`
- 极速性能：端到端约 3 秒出片（上游推理仅约 1.5 秒），成本降低 50%
- 动态多模态分发：传入纯文本自动走极速文生，传入 `image_url` 自动走极速图生
- 异步任务：用返回的 `task_id` 查询 [查询视频任务](/zh/api-reference/tasks/video-task) 或 `GET /v1/tasks/{task_id}`
- 计费：基础 5 秒单次约 $0.25（2.5 积分），传入 `duration: 10` 时自动结算 2.0x 倍率

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 视频系列 |
| 品牌 | MiniMax |
| model | `minimax/h3-max-turbo` |
| 供应商后端 | fal.ai Queue |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/tasks/{task_id}` |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `minimax/h3-max-turbo` |
| `prompt` | string | 条件 | 画面与运镜描述（文生视频必填） |
| `image_url` | string | 条件 | 图生视频首帧图片公网 URL（传入自动切换图生端点） |
| `duration` | number/string | 否 | 时长（支持 `5` 或 `10`，默认 `5`；10 秒结算 2.0x 倍率） |
| `aspect_ratio` | string | 否 | 画幅宽高比，支持 `"16:9"`, `"9:16"`, `"1:1"`，默认 `"16:9"` |
| `prompt_optimizer` | boolean | 否 | 是否启用上游提示词运镜扩写，默认 `true` |

## 响应

### 200（创建成功）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 异步任务 ID，用于状态轮询与结果拉取 |
| `status` | string | 任务初始状态，固定为 `queued` |
| `created` | number | 任务创建时间戳 |

轮询字段见 [查询视频任务](/zh/api-reference/tasks/video-task)。错误见右栏与 [错误码](/zh/faqs/connection-usage)。
