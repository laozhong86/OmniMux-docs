- 创建：`POST /v1/video/generations`，`model` 设为 `minimax-h3-endframe`
- 异步任务：用返回的 `task_id` 查询 [查询视频任务](/zh/api-reference/tasks/video-task)
- 如需通过 `image_with_roles` 统一控制首帧/尾帧/首尾帧，请参考 [MiniMax H3 视频生成](/zh/api-reference/video-series/models/minimax-h3)；实时在线的首尾帧场景分组请见 [MiniMax H3 视频专线](/zh/api-reference/video-series/models/minimax-h3-video)
- 实时可用状态请以[OmniMux 控制台](https://omnimux.ai/dashboard)或 `GET /v1/models` 为准，产物 URL 请及时落盘

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 视频系列 |
| 品牌 | MiniMax |
| model | `minimax-h3-endframe` |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `minimax-h3-endframe` |
| `prompt` | string | 条件 | 引导画面向尾帧过渡的动作与运镜描述 |
| `seconds` / `duration` | number | 否 | 时长（秒，受模型与网关上限约束） |
| `size` / `resolution` | string | 否 | 分辨率（模型相关） |
| `image` / `images` | string/array | 否 | 尾帧参考图 URL 或列表 |

## 响应

### 200（创建）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 id，用于轮询 |
| `status` | string | 如 `queued` / `processing` / `completed` |

轮询字段见 [查询视频任务](/zh/api-reference/tasks/video-task)。错误见右栏与 [错误码](/zh/faqs/connection-usage)。
