---

- 创建：`POST /v1/video/generations`，`model` 固定为 `magi-2`
- 异步任务：用返回的 `task_id` 查询 [查询视频任务](/zh/api-reference/tasks/video-task)
- 原生 1080p 25fps 输出，支持 4 至 30 秒整数时长、同步音频与多模态参考（图片、视频、音频）
- 产物 URL 请及时落盘（上游链接可能有时效）

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 视频系列 |
| 品牌 | Sand AI |
| model | `magi-2` |

## 支持模式

| 模式 (`operation`) | 说明 |
| --- | --- |
| `text_to_video` | 文生视频（`prompt` 必填） |
| `first_frame` | 首帧图生视频（1 张参考图，`prompt` 可选） |
| `first_last_frame` | 首尾帧视频生成（2 张参考图，`prompt` 可选） |
| `video_multi_ref` | 多模态参考生视频（参考图最多 10 张、参考视频最多 5 段、参考音频最多 5 段） |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL：`https://api.omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer sk-...`（API Key） |

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `magi-2` |
| `prompt` | string | 条件 | 文生视频必填，图生与参考模式可选，最长 15000 字符 |
| `duration` | integer | 否 | 视频时长（秒），支持 4 至 30 整数，默认 5 |
| `resolution` | string | 否 | 分辨率，仅支持 `1080p`（默认 `1080p`） |
| `aspect_ratio` | string | 否 | 画面比例，支持 `16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`21:9`（默认 `16:9`） |
| `generate_audio` | boolean | 否 | 是否生成同步音频，默认 `true`（含音频不加价） |
| `image_urls` | array | 否 | 参考图片 HTTPS URL 列表（首帧 1 张，首尾帧 2 张，多模态参考最多 10 张） |
| `video_urls` | array | 否 | 参考视频 HTTPS URL 列表（多模态参考最多 5 段，单段最长 30 秒） |
| `audio_urls` | array | 否 | 参考音频 HTTPS URL 列表（多模态参考最多 5 段，单段最长 30 秒） |

## 响应

### 200（创建）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `task_id` | string | 任务 id，用于轮询 |
| `status` | string | 如 `pending` / `processing` / `completed` |

轮询字段见 [查询视频任务](/zh/api-reference/tasks/video-task)。错误见右栏与 [错误码](/zh/faqs/connection-usage)。
