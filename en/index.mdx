OmniMux is a unified AI model gateway. It aggregates many upstream providers behind one endpoint, with **OpenAI-compatible**, **Claude Messages**, and **Gemini** formats, plus billing, tokens, and channel management.

## Base URL

Production gateway:

```text
https://api.omnimux.ai
```

Point your OpenAI SDK `base_url` / `BASE_URL` at that host and use a console API key to migrate most chat workloads.

<Tip>
  Console: [omnimux.ai](https://omnimux.ai) · Status: [status.omnimux.ai](https://status.omnimux.ai)
