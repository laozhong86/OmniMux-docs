## Platform | API Updates feed opens

`Platform`

*Public developer timeline for model launches, capability changes, pricing, and platform notes.*

OmniMux now publishes an **API Updates** timeline so you can track gateway changes without digging through chats or release notes elsewhere.

## What this feed covers

- **New models** — callable model IDs added on live pricing
- **Model updates** — new modes, durations, resolutions, parameters
- **Pricing** — material rate or settlement changes
- **Breaking** — incompatible request/response or path changes
- **Platform** — auth, domains, and public HTTP surfaces (for example Social Ops publishing)

## How to use OmniMux today

| Surface | URL |
| --- | --- |
| Console | `https://omnimux.ai` |
| OpenAI-compatible API | `https://api.omnimux.ai/v1` |
| Docs | `https://docs.omnimux.ai` |
| Status | `https://status.omnimux.ai` |

Relay auth: Bearer `sk-…` from the console.

## Note on earlier capability

Entries dated **2026-08-09** that describe language, image, video, or social-data families document capabilities **already available** on the gateway when this feed started. They are not fabricated per-model first-launch history. Later entries are append-only real changes.

Full model inventory always lives on console pricing — this page is a **change timeline**, not a second catalog.

## New Model | Video generation — Omni Flash, MiniMax H3, Veo, Kling, Seedance

`New Model`

*Async video SKUs available when this feed opened: create then poll task status.*

Video generation on OmniMux is primarily **async** and **already available** on the gateway:

- Create: `POST /v1/video/generations`
- Poll: `GET /v1/video/generations/{task_id}`

## New Model | Social data — TikTok, Instagram, X, YouTube (read-only)

`New Model`

*Read-only social data models via Chat Completions-style IDs — not publishing.*

**Social data** is **read-only** public content / profile style access. It is **not** social publishing.

## New model

| Platform | Model IDs |
| --- | --- |
| TikTok | `tiktok-user`, `tiktok-posts`, `tiktok-video`, `tiktok-search` |
| Instagram | `instagram-user`, `instagram-posts`, `instagram-post`, `instagram-search` |
| X | `x-user`, `x-posts`, `x-tweet`, `x-search` |
| YouTube | `youtube-user`, `youtube-posts`, `youtube-video`, `youtube-search` |

## Publishing (different surface)

Connect accounts and create posts use **`/api/social/v1/*`** with access token + `New-Api-User` — see **Publishing** in the API manual. Do not mix auth models with gateway `sk-` Chat Completions.
