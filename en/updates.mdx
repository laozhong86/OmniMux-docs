## API Updates feed opens

**2026-08-09** · `Baseline`

*Public developer changelog for model launches, capability changes, pricing, and breaking API notes.*

OmniMux now publishes an **API Updates** feed so you can track what changed on the gateway without digging through release chats.

## What this log covers

- **Model launches** — new callable model ids on live pricing
- **Capability changes** — new modes, durations, resolutions, parameters
- **Pricing** — material rate or settlement changes
- **Breaking** — incompatible request/response or path changes
- **Platform** — auth, domains, public HTTP surfaces (for example Social Ops publishing)

## How to use OmniMux today

| Surface | URL |
| --- | --- |
| Console | `https://omnimux.ai` |
| OpenAI-compatible API | `https://api.omnimux.ai/v1` |
| Docs | `https://docs.omnimux.ai` |
| Status | `https://status.omnimux.ai` |

Auth for relay: Bearer `sk-…` from the console. Quota display: raw_quota ÷ 500000 = USD; **1 USD = 10 credits (积分)**.

## Baseline note

Entries dated **2026-08-09** with type `baseline` describe the **live catalog snapshot** when this feed started. They are not fabricated per-day launch history. Later entries are append-only real changes.
