## How billing is shown

User-facing balance uses **积分 (points)**. Internal raw quota converts as:

- `raw_quota ÷ 500000 = USD`
- **1 USD = 10 积分**

Use the [console](https://omnimux.ai/dashboard) for balance and usage. Account APIs (access token) expose profile/quota fields.

## How to control cost and quality via model tiers & dynamic groups

OmniMux provides native **stateless per-request group routing**, allowing you to choose between cost optimization and production stability with a single API key:

### 1. Three invocation modes

| Tier | Request Syntax | Typical Use Case | Billing & Routing |
| :--- | :--- | :--- | :--- |
| **Default Auto Mode** | Bare model name<br />`"model": "seedance-2-5"` | Onboarding, drafts, batch creation | Default for new keys. Resolves lowest-cost channels first with automatic cross-group retry for SLA protection. |
| **Global Standard Tier** | Add `@standard` suffix<br />`"model": "seedance-2-5@standard"`<br />or `-H "X-Omnimux-Group: standard"` | Production pipelines, official SLA | Fixed **1.0 base multiplier**, routed to official or premier enterprise lines. |
| **Model-Specific Discounts** | Add model-specific group<br />`"model": "seedance-2-5@seedance-cheap"`<br />`"model": "gemini-3.8-flash@gemini-cheap"` | Massive scaling, cost-sensitive jobs | Fixed custom discount (e.g. 75% off for Seedance Cheap, 70% off for Gemini Cheap), physically isolated channels. |

### 2. Code examples

#### Method A: Model Suffix Syntax (Recommended for all clients/SDKs)
```json
{
  "model": "seedance-2-5@seedance-cheap",
  "prompt": "A peaceful ocean wave at sunrise, 4k"
}
```

#### Method B: HTTP Header (Ideal for backend service integration)
```bash
curl -X POST "https://api.omnimux.ai/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-token" \
  -H "Content-Type: application/json" \
  -H "X-Omnimux-Group: gemini-cheap" \
  -d '{
    "model": "gemini-3.8-flash",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Image routing and token reservation

<Info>
  These gateway changes were deployed on October 4, 2026. New plugin capabilities do not constitute a model launch or proof of successful paid generation.
</Info>

### Image requests and groups

For `POST /v1/images/generations` and `/v1/images/edits`, choose an allowed group with `model@group` or `X-Omnimux-Group`. The header takes precedence over the suffix; a group your token cannot use returns 403. Group selection is request-scoped and does not create a new model ID.

An enabled image plugin can handle a matching model; otherwise the gateway retains its existing compatible image processing. Use the published contract for the selected model and group: a plugin capability alone does not make a model available for sale, and not every image response is a pollable task. A timeout or disconnected client does not necessarily cancel an upstream task or guarantee a full refund; check the final task status and billing record before resubmitting.

### Token reservation is not the final charge

Where precharge applies, token-priced requests reserve **estimated input cost × the configured reservation multiplier** (default 1). The output limit (`max_tokens` / `max_completion_tokens`) is no longer added to this estimate. A smaller reservation is not a price reduction or a maximum charge: final settlement still follows actual billable usage and the applicable group price. Keep sensible output limits and sufficient balance.

This multiplier does not change fixed per-call charges or task-usage billing. Quota exemptions and insufficient-quota errors still follow the applicable account and endpoint rules.

## Interrupted streams and tool usage

For Chat Completions served through Responses, and Responses served through Chat Completions, a disconnect can still settle output already delivered. An upstream failure before any output reaches the client is not charged by this converted-stream rule; after output has been delivered, settlement can use reported upstream usage or an estimate of the delivered text, reasoning and tool arguments. This is not a universal refund rule for other endpoints or asynchronous jobs. Inspect the final usage record before resubmitting.

Hosted-search charges follow the provider's reported usage and the applicable tool price. The number of citations is not a reliable search-call count. Gemini grounding can distinguish unique non-empty search queries from a grounded prompt, with the model's configured tool price determining the billing unit. No fixed search price or price reduction is implied by this change.

## How to reduce cost

1. **Pick the right model** — cheaper/smaller models for simple jobs; enum lists capability, not equal price.  
2. **Cap generation** — set sensible `max_tokens` / `max_completion_tokens`.  
3. **Bound multipliers** — image `n`, video duration, resolution affect precharge/settlement; out-of-range values return 400.  
4. **Async video** — create often **precharges**, then **settles** on completion/refund path. Use realistic duration/specs.  
5. **Cache** — cache identical chat or social-data reads on the client.  
6. **Streaming** — `stream: true` can improve UX; abort early only if your product allows and you understand billing still follows live settlement.  
7. **Watch 402** — insufficient balance fails pre-consume with **402** `insufficient_quota`.

## Avoid

- Load-testing expensive video/image models with production keys  
- Calling raw_quota “积分” in product UI  
- Guessing non-live model ids
