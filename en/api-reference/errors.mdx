AI gateway (`sk-`) and most user APIs share these HTTP semantics.

## Status table

| HTTP | Meaning |
| --- | --- |
| `200` | Success |
| `400` | Bad request |
| `401` | Unauthorized / invalid token |
| `402` | Insufficient quota |
| `403` | Forbidden |
| `404` | Not found |
| `429` | Rate limited |
| `500` | Internal error |
| `502` | Upstream / bad gateway |
| `503` | Unavailable |

Model pages include the same status tabs with example JSON bodies.
