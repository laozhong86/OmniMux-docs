openapi: "openapi/ops/influencer/en/creation.json GET /api/influencer/v1/tasks/{task_id}"
---

Use normalized `status` for automation and `artifact_status` for delivery readiness. `succeeded` alone does not guarantee a usable artifact. A failed task or `quota_status: reconciling` does not confirm that credits were refunded.

- Base URL: `https://omnimux.ai`; use a scoped personal access token, not an `sk-` relay key.
- Required permission: `influencer_creation:read`.
- `New-Api-User` is optional compatibility metadata. The credential determines the account; this header cannot choose another owner.

New permissions require a fresh, explicit device approval. Existing and legacy credentials do not expand automatically. See [device login](/en/api-reference/account/device-login).

States: `waiting` → `submitting` → `queued`/`running` → `succeeded` or `failed`. `reconciling` indicates an uncertain submission that must be checked; do not create a replacement request automatically. Stopping a local wait or revoking a token does not cancel an already accepted task.
