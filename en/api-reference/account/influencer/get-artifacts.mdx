openapi: "openapi/ops/influencer/en/creation.json GET /api/influencer/v1/tasks/{task_id}/artifacts"
---

Returns the same safe task projection as task detail, with an `artifacts` array; it does not return file bytes. Only a successful task with usable artifacts reports `artifact_status: ready`. Re-query this endpoint to refresh expired signed content links.

- Base URL: `https://omnimux.ai`; use a scoped personal access token, not an `sk-` relay key.
- Required permission: `influencer_creation:read`.
- `New-Api-User` is optional compatibility metadata. The credential determines the account; this header cannot choose another owner.

New permissions require a fresh, explicit device approval. Existing and legacy credentials do not expand automatically. See [device login](/en/api-reference/account/device-login).

Fetch the API projection using account authentication, then download its signed `content_url` without forwarding that authentication to the content destination or redirects. Do not log signed URLs. Verify the complete, nonempty file before reporting download success. Link expiry is not a reason to submit another generation.
