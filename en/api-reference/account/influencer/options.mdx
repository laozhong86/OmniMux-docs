These pages describe the account HTTP API. The associated new CLI commands are implemented in the project source but are not included in the public 0.4.4 installer release. This documentation does not announce a new CLI distribution release.
</Note>


Read current character options, defaults, media limits and supported resolution/aspect pairs. Check both `creation_enabled` and the relevant `availability` or resolution `available` value. No supplier/model picker is exposed.

- Base URL: `https://omnimux.ai`; use a scoped personal access token, not an `sk-` relay key.
- Required permission: `influencer_creation:read`.
- `New-Api-User` is optional compatibility metadata. The credential determines the account; this header cannot choose another owner.

New permissions require a fresh, explicit device approval. Existing and legacy credentials do not expand automatically. See [device login](/en/api-reference/account/device-login).

<Panel>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://omnimux.ai/api/influencer/v1/options' \
  --header 'Authorization: Bearer <user-access-token>'
```

</RequestExample>
