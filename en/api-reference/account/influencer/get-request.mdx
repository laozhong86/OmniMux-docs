Unpublished draft. No public availability or release date is claimed. Publish only after the service, release gates and documentation update are authorized and verified.
</Warning>

Look up the original task after an uncertain submission or lost response. Recovery never creates another task. Active tasks do not expire; completed tasks have a seven-day recovery period. HTTP 404 means no accepted request is found for this account; HTTP 410 means its recovery is unavailable or expired and the ID remains reserved.

- Base URL: `https://omnimux.ai`; use a scoped personal access token, not an `sk-` relay key.
- Required permission: `influencer_creation:read`.
- `New-Api-User` is optional compatibility metadata. The credential determines the account; this header cannot choose another owner.

New permissions require a fresh, explicit device approval. Existing and legacy credentials do not expand automatically. See [device login](/en/api-reference/account/device-login).
