<Warning>
Unpublished draft. No public availability or release date is claimed. Publish only after the service, release gates and documentation update are authorized and verified.
</Warning>

Supply either `character_task_id` plus optional ordered `image_urls`, or images with `image_urls[0]` as the main character. The combined image limit is 30. Supply exactly one reference video source: `video_url` or an owned successful `video_task_id`.

- Base URL: `https://omnimux.ai`; use a scoped personal access token, not an `sk-` relay key.
- Required permission: `influencer_creation:write`.
- `New-Api-User` is optional compatibility metadata. The credential determines the account; this header cannot choose another owner.

New permissions require a fresh, explicit device approval. Existing and legacy credentials do not expand automatically. See [device login](/en/api-reference/account/device-login).

<Note>
HTTP 200 means durable queue acceptance or recovery, not a finished file or a confirmed charge. Generation uses the existing account credits/subscription allowance. The native execution path uses payment-required (402) semantics for insufficient quota, but this acceptance endpoint does not synchronously emit 402; a queued task may later fail. Read task state and its public failure reason. No precise upfront video quote is promised.
</Note>

Unknown top-level body fields are rejected with 400. Do not send `model`, `group`, `seed`, `size`, or a client-written duration. Reuse the same account-scoped `request_id` and intent to restore an accepted task. Changed content returns 409, and expired recovery returns 410. If the creation switch is off, new requests return 503 `influencer_creation_disabled`; identical accepted replays and owner reads remain available.

The server inspects true duration (4–30 seconds), framing, frame rate, dimensions, codec and audio before accepting generation. MP4/MOV; H.264/HEVC; 24–60 fps; each dimension 300–6000; 407,696–8,295,044 pixels; source aspect 0.4–2.5. Invalid media is rejected, not silently trimmed or padded.

| Resolution | Supported output ratios |
| --- | --- |
| `480p` | `16:9`, `9:16`, `3:4` |
| `720p` | `16:9`, `9:16` |

Defaults: `motion` and `480p`. In motion mode an explicit ratio wins; when omitted, a supported source ratio is used, otherwise `9:16`. Replace mode preserves a supported source ratio and rejects conflicts.

The request preserves image order, passes the reference audio, and uses the saved character's human/cat/dog type. Inspect the finished video to verify appearance, movement, framing and audio; task success alone does not establish creative fidelity.

The 4–30-second limit applies to the reference clip, not a guarantee of the finished video's exact duration. Generated duration may differ: a four-second reference/request has produced a clip of about 3.71 seconds. `duration_sec` is the server-derived integer request duration, not a measurement of the finished video. Reference audio is supplied to generation, but output loudness may change; lossless or bit-for-bit audio preservation is not promised. Check the downloaded video for actual duration and sound.

<RequestExample>

```bash cURL
curl --request POST \
  --url 'https://omnimux.ai/api/influencer/v1/videos' \
  --header 'Authorization: Bearer <user-access-token>' \
  --header 'Content-Type: application/json' \
  --data '{"request_id":"creator-video-0001","character_task_id":"task_example_character","video_url":"https://omnimux.ai/REPLACE_WITH_OWN_REFERENCE.mp4","mode":"motion","resolution":"480p"}'
```
