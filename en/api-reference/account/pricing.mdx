- Public catalog API. No authentication is required.
- Every live model row carries a `contract` object with the model-level capability envelope and, since Contract v2, an executable operation list.

## Identity

| Field | Value |
| --- | --- |
| Series | Account |
| Capability | Public pricing |

## Endpoint

| Method | Path |
| --- | --- |
| `GET` | `/api/pricing` |

Base URL: `https://omnimux.ai`

## Response

### 200

`data` is an array of models. Each row includes `model_name`, `quota_type`, `model_ratio`, `model_price`, `enable_groups`, and `contract`.

The optional top-level `defaults` map recommends a model per operation (`chat`, `vision_chat`, `text_to_image`, `text_to_video`, `text_to_music`, `speech_to_text`). Every value references a model present in the same response with non-empty `enable_groups`; absent recommendations are omitted.

The `contract` object is descriptive only. It never participates in billing, quota or settlement.

| Contract field | Meaning |
| --- | --- |
| `schemaVersion` | Contract shape. `"2.0"` means `operations` is an object array. |
| `contractVersion` | Per-model content hash. Use it to cache one model without re-reading the whole payload. |
| `operations[]` | Executable operations. Each has `id`, `executable`, `inputs[]`, `parameters[]`, and `output.type`. |
| `operation_ids[]` | The same operation ids as a string array, for v1-compatible clients. |
| `unknowns[]` | Field paths whose value the governance spec did not establish. Missing fields are not defaults. |
| `reference_images` / `reference_videos` / `reference_audios` | Declared reference-media limits and accepted formats. |
| `reasoning_efforts` | Optional map from reasoning level to the upstream wire value for text models. |
| `default_reasoning_effort` | Optional default level; when present it is one of the `reasoning_efforts` keys. |

An operation input carries `slot`, `type`, `role`, `required`, `min`, `max`, `allowedMimes`, `maxSizeMb` and duration bounds when declared. A parameter carries `name`, `type`, `enum`, `minimum`, `maximum`, `step`, `default`, `fixed`, and `limitSource`.

`executable: false` means the operation is documented by the vendor but this gateway does not execute it; clients must not submit it.

## Related endpoint

`GET /api/model_contract/:model` returns one model's full v2 contract as `data.contract`, plus the document `version` as `data.version`. A model with no governance spec answers `404`; absence means "not established", not "no such capability".
