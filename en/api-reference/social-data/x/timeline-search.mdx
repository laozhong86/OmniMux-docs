## Endpoint

`POST /v1/chat/completions` · `https://api.omnimux.ai` · `sk-`

## Request example

```bash
curl --request POST \
  --url https://api.omnimux.ai/v1/chat/completions \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "x-search",
  "messages": [{ "role": "user", "content": "." }],
  "keyword": "openai"
}'
```

## Response examples

Status tabs: **200** (data in assistant content) · **400** · **401** · **403** · **429** · **500** · **502** — same shapes as Chinese pages.
