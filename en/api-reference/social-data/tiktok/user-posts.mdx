## Endpoint

`POST /v1/chat/completions` · `https://api.omnimux.ai` · `sk-`

## Request example

```bash
curl --request POST \
  --url https://api.omnimux.ai/v1/chat/completions \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "tiktok-posts",
  "messages": [{ "role": "user", "content": "." }],
  "unique_id": "tiktok"
}'
```
