- Create: `POST /v1/video/generations` with `model` `index-tts`
- Poll: `GET /v1/video/generations/{task_id}` (do **not** use `*-async` / `*-query` names)
- GxgenAI tasks share this path even when the result is audio
- `metadata.nodeInfoList` is required (reference audio + script)
- Upload the reference clip first (public URL or upstream file name). Raw `data:` URIs fail
- Persist result URLs promptly

## Identity

| Field | Value |
| --- | --- |
| Series | Audio |
| Brand | Index TTS / GxgenAI |
| model | `index-tts` |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `index-tts` |
| `prompt` | string | no | Label only; script goes in node `7` |
| `metadata.nodeInfoList` | array | **yes** | Reference audio + text |

Required nodes:

| nodeId | fieldName | Meaning |
| --- | --- | --- |
| `4` | `audio` | Reference voice (first ~15s is used) |
| `7` | `text` | Script to speak |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `id` / `task_id` | string | Task id |
| `status` | string | `queued` / `in_progress` / `completed` |

Poll [Video task](/en/api-reference/tasks/video-task). Errors: [Error codes](/en/faqs/connection-usage).
