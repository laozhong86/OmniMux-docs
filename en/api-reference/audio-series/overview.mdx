Audio APIs use the **AI gateway** (`sk-` Bearer). Base URL:

```text
https://api.omnimux.ai
```

## What you can do

| Capability | Method | Path | Notes |
| --- | --- | --- | --- |
| Text-to-speech (TTS) | `POST` | `/v1/audio/speech` | Audio stream/file (channel-dependent) |
| Transcription | `POST` | `/v1/audio/transcriptions` | Speech → text (often multipart) |
| Translation | `POST` | `/v1/audio/translations` | Speech → target-language text |

Full fields and content types are under Audio ops in the [OpenAPI appendix](/en/api-reference/appendix/openapi).

## Auth

```http
Authorization: Bearer sk-xxxxxxxx
```

## Quick example (TTS)

```bash
curl -sS https://api.omnimux.ai/v1/audio/speech \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_TTS_MODEL",
    "input": "Hello from OmniMux",
    "voice": "alloy"
  }' \
  --output speech.mp3
```

`model` / `voice` depend on your enabled models and upstream support.
