- 调用 `POST /v1/images/generations`，`model` 为 `nano-banana-2-lite`
- 请求体至少包含 `model` 与 `prompt`
- 官方轻量级高性价比生图模型，适合低成本大规模批量生成

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 图像系列 |
| 品牌 | Google / Nano Banana |
| 公开 model（OmniMux） | `nano-banana-2-lite` |
| 官方 model（上游 SKU） | `gemini-3.1-flash-lite-image` |
| 基准定价 | $0.0336 / 张（1K 分辨率） |

The public model ID is `nano-banana-2-lite`. Google's official model ID `gemini-3.1-flash-lite-image` is the upstream SKU only — send the public ID in requests.

## 请求体

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `nano-banana-2-lite` |
| `prompt` | string | 是 | Image generation prompt description |
| `size` | string | 否 | 长宽比，如 `1:1`, `9:16`, `16:9`，默认为 `1:1` |
