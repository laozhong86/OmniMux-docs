- Create or reference-generate via `POST /v1/images/generations` with `model` set to `grok-imagine-image-quality`; edit an existing image via `POST /v1/images/edits`
- Supports OpenAI-compatible parameters `aspect_ratio` (automatically mapped to `size` when `size` is omitted) and `response_format` (`url` or `b64_json`)
- Confirm live model availability and pricing in the [OmniMux console](https://omnimux.ai/dashboard) or via `GET /v1/models`; see [Grok Imagine Image](/en/api-reference/image-series/models/grok-imagine-image) for the standard model
- If the upstream returns an async `task_id` / `id`, track task completion in console usage logs

## Identity

| Field | Value |
| --- | --- |
| Series | Image series |
| Brand | Grok Imagine |
| model | `grok-imagine-image-quality` |

## Grok Imagine Variants

| Model ID | Tier | Endpoint | Guide |
| --- | --- | --- | --- |
| `grok-imagine-image` | Standard | `POST /v1/images/generations` · `/v1/images/edits` | [Grok Imagine Image](/en/api-reference/image-series/models/grok-imagine-image) |
| `grok-imagine-image-quality` | Quality tier | `POST /v1/images/generations` · `/v1/images/edits` | This page |
| `grok-imagine-image-2-0` | 2.0 generation | `POST /v1/images/generations` · `/v1/images/edits` | [Grok Imagine Image 2.0](/en/api-reference/image-series/models/grok-imagine-image-2-0) |

## Endpoint

| Method | Path | Use |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | Text-to-image and optional reference-guided generation |
| `POST` | `/v1/images/edits` | Image editing (requires at least one reference image) |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `grok-imagine-image-quality` |
| `prompt` | string | yes | Image description or edit instruction |
| `n` | integer | no | Number of images (gateway-capped) |
| `size` | string | no | Size or aspect ratio (model-specific) |
| `aspect_ratio` | string | no | Aspect ratio; automatically normalized to `size` when `size` is omitted |
| `response_format` | string | no | Output delivery format: `url` or `b64_json` |
| `quality` | string | no | Quality tier (model-specific) |
| `images` | string[] | conditional | Reference images as URL or base64 (`required` on `POST /v1/images/edits`). `image`, `image_urls`, and `input_reference` are accepted aliases and normalized to `images` before forwarding. |

### Reference image limits

No formal model spec exists for this model yet, so its exact reference-image count, accepted formats, and per-file size ceiling remain **unverified** here.

## Response

### 200

| Field | Type | Description |
| --- | --- | --- |
| `created` | integer | Creation timestamp when present (sync responses) |
| `data` | array | Image objects carrying `url` or `b64_json`, and optional `revised_prompt` |
| `task_id` / `id` | string | Async task id when the upstream submits a background job |

Errors: see right-rail examples and [Error codes](/en/faqs/connection-usage). Async: use `task_id` from the create response and console usage logs (no separate public image-query endpoint).

<RequestExample>

```bash cURL (Generations with aspect_ratio & b64_json)
curl --request POST \
  --url https://api.omnimux.ai/v1/images/generations \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "grok-imagine-image-quality",
  "prompt": "a product photo on white background",
  "aspect_ratio": "16:9",
  "response_format": "b64_json",
  "n": 1
}'
```

```bash cURL (Image Edits)
curl --request POST \
  --url https://api.omnimux.ai/v1/images/edits \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "grok-imagine-image-quality",
  "prompt": "change the studio backdrop to warm morning sunlight",
  "images": ["https://example.com/product.jpg"],
  "aspect_ratio": "1:1"
}'
```

</RequestExample>
