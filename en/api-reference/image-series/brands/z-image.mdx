Brand：**Z Image**（GxgenAI）

GxgenAI Z Image apps; poll when using `*-async` models.

## Recommended protocols

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | Image generation / async task |

## Example models

| model |
| --- |
| `zimage-makeup` |
| `zimage-makeup-async` |

Snapshot examples only — **not** a guarantee of availability. Use `GET /v1/models` and the Model Square.

## Example call

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zimage-makeup",
    "prompt": "a product on white background",
    "n": 1
  }'
```
