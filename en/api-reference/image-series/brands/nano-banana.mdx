Brand：**Nano Banana**（Google）

Google image brand. Async depends on channel; see [Async tasks](/en/api-reference/cross-cutting/async-tasks).

## Recommended protocols

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | OpenAI Images (channel-dependent) |
| `POST` | `/v1beta/models/{model}:generateContent` | Gemini-native image |

## Example models

| model |
| --- |
| `nano_banana_pro` |
| `nano_banana_2` |

Snapshot examples only — **not** a guarantee of availability. Use `GET /v1/models` and the Model Square.

## Example call

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano_banana_pro",
    "prompt": "a product on white background",
    "n": 1
  }'
```
