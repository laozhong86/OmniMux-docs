This group covers **text chat, completions, embeddings, and model listing** (organized by protocol surface).  
For image / video / audio / social publish, use the other sidebar groups:

- [Image](/en/api-reference/image-series/overview)  
- [Video](/en/api-reference/video-series/overview)  
- [Audio](/en/api-reference/audio-series/overview)  
- [Social Ops](/en/api-reference/social-ops)  

## Base URL

```text
https://api.omnimux.ai
```

Typical OpenAI-compatible SDK value:

```text
https://api.omnimux.ai/v1
```

Auth: `Authorization: Bearer sk-...`. See [Authentication](/en/guides/authentication).

## OpenAI-compatible

| Capability | Method | Path |
| --- | --- | --- |
| Chat Completions | `POST` | `/v1/chat/completions` |
| Completions | `POST` | `/v1/completions` |
| Responses | `POST` | `/v1/responses` |
| Responses compact | `POST` | `/v1/responses/compact` |
| Embeddings | `POST` | `/v1/embeddings` |
| Moderations | `POST` | `/v1/moderations` |
| Rerank | `POST` | `/v1/rerank` |
| List models | `GET` | `/v1/models` |
| Realtime | `GET` | `/v1/realtime` (WebSocket upgrade; follow live behavior) |
| Images | `POST` | `/v1/images/generations` · `/v1/images/edits` |
| Audio | `POST` | `/v1/audio/*` |
| Video (unified / Sora-style) | `POST`/`GET` | `/v1/video/generations` · `/v1/videos` |

## Gemini-style

| Capability | Method | Path |
| --- | --- | --- |
| List models | `GET` | `/v1beta/models` |

| Embeddings (engine path) | `POST` | `/v1/engines/{model}/embeddings` |
