This page indexes **shared language protocols**. For brand discovery start here:

**[Language series](/en/api-reference/text-series/overview)** → Claude / Gemini / GPT / Grok / …

## Base URL

```text
https://api.omnimux.ai
```

Auth: `Authorization: Bearer sk-...`.

## Common protocols

| Capability | Method | Path |
| --- | --- | --- |
| Chat Completions | `POST` | `/v1/chat/completions` |
| Completions | `POST` | `/v1/completions` |
| Responses | `POST` | `/v1/responses` |
| Responses compact | `POST` | `/v1/responses/compact` |
| Claude Messages | `POST` | `/v1/messages` |
| List models | `GET` | `/v1/models` |
| Gemini model list | `GET` | `/v1beta/models` |
| Gemini generateContent | `POST` | `/v1beta/models/{model}:generateContent` |
| Embeddings | `POST` | `/v1/embeddings` |
| Moderations | `POST` | `/v1/moderations` |
| Rerank | `POST` | `/v1/rerank` |
| Realtime | `GET` | `/v1/realtime` |

Try-it for these paths lives under **Language series → Protocol endpoints** in the sidebar.
