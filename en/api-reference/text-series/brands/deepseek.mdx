## Example call

```bash
curl -sS https://api.omnimux.ai/v1/chat/completions \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [{
      "role": "user",
      "content": "Hello"
    }]
  }'
```
