## Example call

```bash
curl -sS https://api.omnimux.ai/v1/chat/completions \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "messages": [{
      "role": "user",
      "content": "Hello"
    }]
  }'
```
