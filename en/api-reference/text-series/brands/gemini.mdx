Brand：**Gemini**（Google）

Use Chat Completions for text. Image models (Nano Banana) live under [Image · Nano Banana](/en/api-reference/image-series/brands/nano-banana).

## Recommended protocols

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/v1/chat/completions` | OpenAI Chat-compatible |
| `POST` | `/v1beta/models/{model}:generateContent` | Gemini-native (incl. some multimodal) |
| `GET` | `/v1beta/models` | Gemini-style model list |

## Example call

```bash
curl -sS https://api.omnimux.ai/v1/chat/completions \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.6-flash",
    "messages": [{
      "role": "user",
      "content": "Hello"
    }]
  }'
```
