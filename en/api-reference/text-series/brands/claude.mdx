Brand：**Claude**（Anthropic）

Prefer `/v1/messages` for Claude-native; Chat Completions also works. `model` must be enabled for your account.

## Recommended protocols

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/v1/messages` | Anthropic Messages-native |
| `POST` | `/v1/chat/completions` | OpenAI Chat-compatible |

## Example call

```bash
curl -sS https://api.omnimux.ai/v1/messages \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-5",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```
