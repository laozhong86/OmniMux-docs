Model tables on brand pages are snapshots — trust **`GET /v1/models`** and the console.

## Protocol vs brand

- **Brand pages**: pick a family, see recommended protocols and example ids  
- **Protocol endpoints** (below this group in the sidebar): Chat / Messages / Responses / model list try-it  

One `POST /v1/chat/completions` serves many brands; the difference is the `model` field.
