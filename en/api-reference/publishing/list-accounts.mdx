---
title: "List accounts"
description: "GET /api/social/v1/accounts"
---

| Field | Value |
| --- | --- |
| Method | `GET` |
| URL | `https://omnimux.ai/api/social/v1/accounts` |
| Auth | access token + `New-Api-User` |

## Request example

<CodeGroup>
```bash cURL
curl --request GET \
  --url https://omnimux.ai/api/social/v1/accounts \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json'
```
</CodeGroup>
