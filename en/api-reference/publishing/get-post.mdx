description: "GET /api/social/v1/posts/{id}"
---

| Field | Value |
| --- | --- |
| Method | `GET` |
| URL | `https://omnimux.ai/api/social/v1/posts/{id}` |
| Auth | access token + `New-Api-User` |



<RequestExample>

```bash cURL
curl --request GET \
  --url https://omnimux.ai/api/social/v1/posts/{id} \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json'
```

</RequestExample>
