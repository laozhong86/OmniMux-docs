Starts the platform's official authorization flow. Only TikTok direct (Login Kit + Content Posting API) is available; other platforms are not offered yet and return 400 `SOCIAL_PLATFORM_DENIED`.

<Note>
  The TikTok developer submission is still under platform review. Until it is approved, authorization and publishing may work only for platform test accounts; API errors do not indicate the review outcome.
</Note>

`provider` is required and has one current value, `tiktok_direct`. A retired source identifier returns 410 `provider-retired`; missing or unknown values return 400 `invalid-provider`.

Use an OmniMux user access token and `New-Api-User`, not an `sk-` key. Inspect `success` as well as HTTP status; some upstream failures return HTTP 200 with `success:false`.
