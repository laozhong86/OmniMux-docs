---
title: "Start connect"
description: "POST /api/social/v1/connect"
---

| Field | Value |
| --- | --- |
| Method | `POST` |
| URL | `https://omnimux.ai/api/social/v1/connect` |
| Auth | access token + `New-Api-User` |

## Request example

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://omnimux.ai/api/social/v1/connect \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json' \
  --data '{"platform":"tiktok"}'
```
</CodeGroup>
