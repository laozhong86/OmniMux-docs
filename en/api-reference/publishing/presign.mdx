Requests a one-time upload ticket for publishing media. The ticket signs against the gateway's own object storage, never a third-party bucket. After uploading, pass the returned `public_url` as the post's `media` reference.

## Identity

| Field | Value |
| --- | --- |
| Series | Publishing |
| Group | Media |
| Capability | Request upload |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/api/social/v1/media/presign` |

Base URL: `https://omnimux.ai`

## Authorization

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer <access_token>` (user access token) |
| `New-Api-User` | header | string | yes | Current user id |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `filename` | string | yes | Original filename; only the extension shapes the object key |
| `content_type` | string | yes | MIME type; `contentType` is also accepted |
| `size_bytes` | integer | no | Single-file limit check; defaults to 512 MiB |

The object key is generated server-side and cannot be chosen by the client.

## Response 200

| Field | Type | Description |
| --- | --- | --- |
| `upload_url` | string | Target for the direct `PUT` |
| `upload_method` | string | Usually `PUT` |
| `headers` | object | Headers to send verbatim with the upload (`Content-Type`) |
| `public_url` | string | Platform-readable URL; use it as the post `media` reference |
| `key` | string | Server-generated object key |
| `expires_in` | integer | Remaining ticket lifetime in seconds |
| `filename` / `content_type` | string | Echo of the request values |

## Upload

Upload directly to `upload_url` and do not attach gateway credentials:

```bash
curl --request PUT --upload-file ./clip.mp4 \
  --header 'Content-Type: video/mp4' \
  '<upload_url>'
```

Do not submit the post when the upload failed, the ticket expired, or the object is unreadable; request a new ticket instead.

<Panel>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://omnimux.ai/api/social/v1/media/presign \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json' \
  --data '{"filename":"clip.mp4","content_type":"video/mp4","size_bytes":10485760}'
```

</RequestExample>
