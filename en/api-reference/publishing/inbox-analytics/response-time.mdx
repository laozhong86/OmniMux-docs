- Social **publishing** user API (not `sk-` social-data read)
- Base: `https://omnimux.ai`; auth access token + `New-Api-User`
- Evaluates agent and operator response latency, median time-to-first-response (TTFR), and resolution speed

## Identity

| Field | Value |
| --- | --- |
| Series | Publishing |
| Group | Inbox Analytics |
| Capability | Inbox response time |

## Endpoint

| Method | Path |
| --- | --- |
| `GET` | `/api/social/v1/inbox-analytics/response-time` |

Base URL: `https://omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer <access_token>` (User Access Token) |
| `New-Api-User` | header | string | yes | Current user id |

## Query Parameters

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `platform` | string | no | — | Filter by platform (`tiktok`, `x`, `instagram`, `youtube`) |
| `fromDate` | string | no | 30 days ago | Start date (`YYYY-MM-DD`) |
| `toDate` | string | no | Today | End date (`YYYY-MM-DD`) |

## Response

### 200

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Success flag |
| `data.medianResponseTimeMinutes` | number | Median response time in minutes |
| `data.averageResponseTimeMinutes` | number | Average response time in minutes |
| `data.buckets` | array | Latency distribution brackets (`<15m`, `15-60m`, `1-4h`, `4-24h`, `>24h`) |
| `data.resolvedConversations` | integer | Total conversations handled and resolved |

Errors: right rail and [Error codes](/en/faqs/connection-usage).
