- Social **publishing** user API (not `sk-` social-data read)
- Base: `https://omnimux.ai`; auth access token + `New-Api-User`
- Analyzes the proportional distribution of incoming interactions across connected social platforms

## Identity

| Field | Value |
| --- | --- |
| Series | Publishing |
| Group | Inbox Analytics |
| Capability | Inbox source breakdown |

## Endpoint

| Method | Path |
| --- | --- |
| `GET` | `/api/social/v1/inbox-analytics/source-breakdown` |

Base URL: `https://omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer <access_token>` (User Access Token) |
| `New-Api-User` | header | string | yes | Current user id |

## Query Parameters

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `platform` | string | no | — | Filter by platform (`tiktok`, `x`, `instagram`, `youtube`) |
| `fromDate` | string | no | 30 days ago | Start date (`YYYY-MM-DD`) |
| `toDate` | string | no | Today | End date (`YYYY-MM-DD`) |

## Response

### 200

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Success flag |
| `data.platforms` | array | Breakdown of messages by social platform |
| `data.platforms[].platform` | string | Platform name |
| `data.platforms[].messageCount` | integer | Total inbound messages on this platform |
| `data.platforms[].percentage` | number | Percentage of total inbox volume (%) |
| `data.totalMessages` | integer | Grand total incoming messages across all sources |

Errors: right rail and [Error codes](/en/faqs/connection-usage).
