description: "OAuth connect, list, and disconnect social accounts."
---

Official Zernio guide name: **Connecting Accounts**.

| Capability | Method | Path |
| --- | --- | --- |
| Start connect | `POST` | `/api/social/v1/connect` |
| List accounts | `GET` | `/api/social/v1/accounts` |
| Disconnect | `DELETE` | `/api/social/v1/accounts/{id}` |
