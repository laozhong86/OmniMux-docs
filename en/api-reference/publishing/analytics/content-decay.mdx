- Social **publishing** user API (not `sk-` social-data read)
- Base: `https://omnimux.ai`; auth access token + `New-Api-User`
- Measures engagement accumulation across post-publishing time windows to determine content half-life

## Identity

| Field | Value |
| --- | --- |
| Series | Publishing |
| Group | Analytics |
| Capability | Content decay |

## Endpoint

| Method | Path |
| --- | --- |
| `GET` | `/api/social/v1/analytics/content-decay` |

Base URL: `https://omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer <access_token>` (User Access Token) |
| `New-Api-User` | header | string | yes | Current user id |

## Query Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `platform` | string | no | Filter by platform (`tiktok`, `x`, `instagram`, `youtube`) |

## Response

### 200

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Success flag |
| `data.buckets` | array | Time window cumulative engagement buckets |
| `data.buckets[].bucketOrder` | integer | Sequential index (0-5) |
| `data.buckets[].bucketLabel` | string | Window label (`0-6h`, `6-12h`, `12-24h`, `1-2d`, `2-7d`, `7-30d`) |
| `data.buckets[].avgPctOfFinal` | number | Average percentage of final total engagement achieved |
| `data.buckets[].postCount` | integer | Posts sample size |
| `data.milestones` | object | Milestones (50% half-life window and 80% ceiling window) |

Errors: right rail and [Error codes](/en/faqs/connection-usage).
