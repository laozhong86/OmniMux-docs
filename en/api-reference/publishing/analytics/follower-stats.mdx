- Social **publishing** user API (not `sk-` social-data read)
- Base: `https://omnimux.ai`; auth access token + `New-Api-User`
- Retrieves multi-platform follower count evolution, net growth, and daily timeline snapshots

## Identity

| Field | Value |
| --- | --- |
| Series | Publishing |
| Group | Analytics |
| Capability | Follower stats |

## Endpoint

| Method | Path |
| --- | --- |
| `GET` | `/api/social/v1/accounts/follower-stats` |

Base URL: `https://omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer <access_token>` (User Access Token) |
| `New-Api-User` | header | string | yes | Current user id |

## Query Parameters

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `days` | integer | no | `30` | Number of historical days to inspect (1-90) |
| `account_ids` | string | no | — | Comma-separated list of local numeric account IDs |

## Response

### 200

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Success flag |
| `data.accounts` | array | Per-account summary metrics |
| `data.accounts[].accountId` | string | Provider account id |
| `data.accounts[].platform` | string | Social platform |
| `data.accounts[].username` | string | Handle / username |
| `data.accounts[].currentFollowers` | integer | Current follower count |
| `data.accounts[].growth` | integer | Net follower growth over the period |
| `data.accounts[].growthPercentage` | number | Percentage growth rate (%) |
| `data.timeline` | array | Historical daily follower totals and breakdown |

Errors: right rail and [Error codes](/en/faqs/connection-usage).
