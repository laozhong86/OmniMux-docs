- Social **publishing** user API (not `sk-` social-data read)
- Base: `https://omnimux.ai`; auth access token + `New-Api-User`
- Analyzes historical engagement to compute hourly effectiveness scores across all 7 days of the week

## Identity

| Field | Value |
| --- | --- |
| Series | Publishing |
| Group | Analytics |
| Capability | Best time to post |

## Endpoint

| Method | Path |
| --- | --- |
| `GET` | `/api/social/v1/analytics/best-time-to-post` |

Base URL: `https://omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer <access_token>` (User Access Token) |
| `New-Api-User` | header | string | yes | Current user id |

## Query Parameters

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `platform` | string | no | — | Filter by platform (default all platforms) |
| `account_id` | integer | no | — | Filter by single local numeric account ID |
| `timezone` | string | no | `UTC` | Timezone identifier (e.g. `Asia/Shanghai`, `America/New_York`) |

## Response

### 200

| Field | Type | Description |
| --- | --- | --- |
| `success` | boolean | Success flag |
| `data.slots` | array | 7x24 hourly engagement slots |
| `data.slots[].dayOfWeek` | integer | Day of week (0 = Sunday, 1 = Monday, ..., 6 = Saturday) |
| `data.slots[].hour` | integer | Hour of day (0-23) |
| `data.slots[].avgEngagement` | number | Average engagement score for this slot |
| `data.slots[].postCount` | integer | Total posts analyzed in this slot |
| `data.recommended` | array | Ranked list of recommended top time slots |

Errors: right rail and [Error codes](/en/faqs/connection-usage).
