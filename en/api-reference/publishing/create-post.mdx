title: "Create post"
description: "POST /api/social/v1/posts"
---

| Field | Value |
| --- | --- |
| Method | `POST` |
| URL | `https://omnimux.ai/api/social/v1/posts` |
| Auth | access token + `New-Api-User` |

## Request example

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://omnimux.ai/api/social/v1/posts \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json' \
  --data '{"account_ids":[1],"text":"hello","media_items":[{"url":"https://example.com/a.png"}]}'
```
</CodeGroup>
