| Field | Value |
| --- | --- |
| Method | `GET` |
| URL | `https://api.omnimux.ai/v1/videos/{task_id}/content` |
| Auth | `sk-` Bearer |

## Request example

```bash
curl --request GET \
  --url https://api.omnimux.ai/v1/videos/$TASK_ID/content \
  --header 'Authorization: Bearer <token>'
```
