Interactive **AI gateway** ops on this site come from the in-repo snapshot:

```text
openapi/relay.json
```

It is synced from the product repo `docs/openapi/relay.json`. It does **not** include Admin OpenAPI, and it does **not** include non-relay user APIs such as Social Ops.

## How to use

1. Expand endpoints under **Image / Video / Audio / Text & models** in the sidebar (try-it)  
2. Set `Authorization: Bearer sk-...` and the body, then try the call  
3. Use Base URL `https://api.omnimux.ai` (playground host follows site config)

This page only describes the snapshot source and boundaries. The appendix **does not** re-list the full OpenAPI dump in the sidebar.

## Sync

When product OpenAPI changes, refresh `openapi/relay.json` in this repo before publishing. Placeholder or unimplemented paths should not ship in the public snapshot.
