- Create: `POST /v1/video/generations` with `model` set to `seedance-2-0-mini`
- Async: poll [Video task](/en/api-reference/tasks/video-task) with the returned `task_id`
- Supports 480p and 720p output, 4–15s durations, optional audio generation, frame-guided generation, and multimodal references
- Confirm live availability and current pricing in the [OmniMux console](https://omnimux.ai/dashboard) or `GET /v1/models`; for the newer fast multimodal release, see [Seedance 2.5 Flash Video Generation](/en/api-reference/video-series/models/seedance-2-5-flash)
- Persist result URLs promptly (upstream links may expire)

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | Seedance |
| model | `seedance-2-0-mini` |

## Supported Modes

| Mode (`operation`) | Input Requirements | Notes |
| --- | --- | --- |
| `text_to_video` | `prompt` | Supports `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, `adaptive` |
| `first_frame` | `prompt` + `image_with_roles` (`role: "first"`) | `aspect_ratio` is fixed to `adaptive` |
| `first_last_frame` | `prompt` + `image_with_roles` (`role: "first"` and `"last"`) | Supports `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, `adaptive` |
| `video_multi_ref` | `prompt` + `image_urls` / `video_urls` / `audio_urls` | Up to 9 images, 3 videos, 3 audio clips |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `seedance-2-0-mini` |
| `prompt` | string | yes | Video generation prompt |
| `duration` / `seconds` | integer | no | Output duration in seconds (integer `4` to `15`, step `1`) |
| `resolution` | string | no | Output resolution: `480p` or `720p` |
| `aspect_ratio` / `size` | string | no | `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, or `adaptive` (fixed `adaptive` for `first_frame`) |
| `generate_audio` | boolean | no | Whether to generate synchronized audio, default `false` |
| `image_with_roles` | array | no | Role-tagged images for `first_frame` / `first_last_frame` (e.g. `{"url":"...","role":"first"}`); JPEG/PNG/WebP/BMP/TIFF/GIF/HEIC/HEIF up to 30 MB |
| `image_urls` | array | no | Multimodal reference image URLs (up to 9) |
| `video_urls` | array | no | Multimodal reference video URLs (up to 3, MP4/MOV up to 50 MB) |
| `audio_urls` | array | no | Multimodal reference audio URLs (up to 3, WAV/MP3 up to 15 MB) |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `queued` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).

<RequestExample>

```bash cURL (Text-to-Video)
curl --request POST \
  --url https://api.omnimux.ai/v1/video/generations \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "seedance-2-0-mini",
  "prompt": "Slow pan across a handcrafted ceramic mug on a sunlit wooden table",
  "duration": 5,
  "resolution": "720p",
  "aspect_ratio": "16:9",
  "generate_audio": false
}'
```

```bash cURL (First-Last Frame)
curl --request POST \
  --url https://api.omnimux.ai/v1/video/generations \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "seedance-2-0-mini",
  "prompt": "Smooth camera orbit between the opening and closing studio frames",
  "duration": 5,
  "resolution": "720p",
  "image_with_roles": [
    { "url": "https://example.com/first.jpg", "role": "first" },
    { "url": "https://example.com/last.jpg", "role": "last" }
  ]
}'
```
