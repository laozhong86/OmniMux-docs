- Create: `POST /v1/video/generations` with `model` set to `seedance-2-0-fast`
- Async: poll [Video task](/en/api-reference/tasks/video-task) with returned `task_id`
- Supports `480p` and `720p` output, `4–15s` durations, optional audio generation, frame-guided modes, and multimodal reference inputs
- Confirm live availability via the [OmniMux console](https://omnimux.ai/dashboard) or `GET /v1/models`; see also [Seedance 2.0](/en/api-reference/video-series/models/seedance-2-0) and [Seedance 2.5 Flash](/en/api-reference/video-series/models/seedance-2-5-flash)
- Persist result URLs promptly (upstream links may expire)

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | Seedance |
| model | `seedance-2-0-fast` |

## Supported Modes

| Mode (`operation`) | Input Requirements | Aspect Ratio |
| --- | --- | --- |
| `text_to_video` | `prompt` | `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, `adaptive` |
| `first_frame` | `prompt` + `image_with_roles` (`role: "first"`) | Fixed `adaptive` |
| `first_last_frame` | `prompt` + `image_with_roles` (`role: "first"` and `"last"`) | Fixed `adaptive` |
| `video_multi_ref` | `prompt` + `image_urls` / `video_urls` / `audio_urls` | `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, `adaptive` |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `seedance-2-0-fast` |
| `prompt` | string | yes | Video generation prompt |
| `duration` / `seconds` | integer | no | Output duration in seconds (`4` to `15`) |
| `resolution` | string | no | `480p` or `720p` |
| `aspect_ratio` / `size` | string | no | `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, or `adaptive` (fixed `adaptive` for frame-guided modes) |
| `generate_audio` | boolean | no | Generate synchronized audio, default `false` |
| `image_with_roles` | array | no | Role-tagged images for `first_frame` / `first_last_frame` (up to 30 MB per image) |
| `image_urls` | array | no | Multimodal reference image URLs (up to 9, max 30 MB each) |
| `video_urls` | array | no | Multimodal reference video URLs (up to 3, max 200 MB each) |
| `audio_urls` | array | no | Multimodal reference audio URLs (up to 3, max 15 MB each) |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `queued` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).
