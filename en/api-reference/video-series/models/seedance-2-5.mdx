- Create: `POST /v1/video/generations` with `model` `seedance-2-5` (standard) or `seedance-2-5-task` (fixed per-call task path)
- Async: poll [Video task](/en/api-reference/tasks/video-task) with returned `task_id`
- Supports `480p`, `720p`, and `1080p` resolutions, `4–30s` durations (`-1` auto duration in `video_edit`), `mp4` / `mov` output, optional `generate_audio` (default `false`), and 6 modes (`text_to_video`, `first_frame`, `first_last_frame`, `video_multi_ref`, `video_edit`, `video_extend`)
- Confirm live pricing in the [OmniMux console](https://omnimux.ai/dashboard) or `GET /v1/models`; see also [Seedance 2.5 Flash](/en/api-reference/video-series/models/seedance-2-5-flash)
- Persist result URLs promptly (upstream links may expire)

<Note>
Reference-video intake in the character workbench has its own [input requirements and editing boundaries](/en/faqs/features#reference-video-checks-in-the-character-workbench). Those checks and the signed-in website preflight are not an additional public `/v1` endpoint or new parameters for this API. Reference input ratio and generated output ratio are separate requirements.
</Note>

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | ByteDance |
| model | `seedance-2-5`, `seedance-2-5-task` |

## Supported Modes

| Mode (`operation`) | Input Requirements | Aspect Ratio & Parameter Constraints |
| --- | --- | --- |
| `text_to_video` | `prompt` | `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `adaptive` |
| `first_frame` | `prompt` + `image_with_roles` (`role: "first"`) | Fixed `adaptive` (single image `<= 30 MB`) |
| `first_last_frame` | `prompt` + `image_with_roles` (`role: "first"` and `"last"`) | Fixed `adaptive` (each image `<= 30 MB`) |
| `video_multi_ref` | `prompt` + `image_urls` / `video_urls` / `audio_urls` | `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `adaptive` (`1–30` images `<= 30 MB`, `0–10` videos `<= 200 MB`, `0–10` audios `<= 15 MB`) |
| `video_edit` | `prompt` + 1 source video in `video_urls` | Fixed `adaptive` and fixed `duration: -1` (pass explicit `operation: "video_edit"`) |
| `video_extend` | `prompt` + 1 source video in `video_urls` | Fixed `adaptive`, `duration` `4–30s` (pass explicit `operation: "video_extend"`) |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `seedance-2-5` (standard) or `seedance-2-5-task` (fixed per-call task path) |
| `operation` | string | conditional | `text_to_video`, `first_frame`, `first_last_frame`, `video_multi_ref`, `video_edit`, or `video_extend` (explicitly required when passing `video_urls`) |
| `prompt` | string | yes | Video generation or editing prompt |
| `duration` / `seconds` | integer | no | Output duration in seconds (`4` to `30`; `video_edit` requires `-1` when set) |
| `resolution` | string | no | `480p`, `720p`, or `1080p` |
| `aspect_ratio` / `size` | string | no | `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, or `adaptive` (fixed `adaptive` for `first_frame`, `first_last_frame`, `video_edit`, and `video_extend`) |
| `output_format` | string | no | Output container format: `mp4` or `mov` |
| `generate_audio` | boolean | no | Generate synchronized audio, default `false` |
| `image_with_roles` | array | no | Role-tagged images for `first_frame` / `first_last_frame` (`role: "first"` / `"last"` or `"first_frame"` / `"last_frame"`) |
| `image_urls` | array | no | Reference image URLs (`1–30` images, `<= 30 MB` each; JPEG/PNG/WebP/BMP/TIFF/GIF/HEIC/HEIF) |
| `video_urls` | array | no | Reference videos (up to `10` in `video_multi_ref`) or 1 source video (`video_edit` / `video_extend`), MP4/QuickTime `<= 200 MB` |
| `audio_urls` | array | no | Reference audio URLs (`0–10`, WAV/MP3 `<= 15 MB` each) for `video_multi_ref` |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `queued` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).
