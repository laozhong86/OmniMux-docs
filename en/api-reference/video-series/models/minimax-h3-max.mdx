- Create: `POST /v1/video/generations` with `model: "minimax/h3-max"`
- Dynamic Multimodal Dispatch: pass text-only for text-to-video, `image_url` for image-to-video, or `video_url` for reference-to-video
- Async Task: query task status and result with `task_id` via [Query Video Task](/en/api-reference/tasks/video-task) or `GET /v1/tasks/{task_id}`
- Pricing: base 5s call ~$0.50 (5 credits); `duration: 10` automatically settles with 2.0x multiplier

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | MiniMax |
| model | `minimax/h3-max` |
| Upstream Backend | fal.ai Queue |

## Endpoints

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/tasks/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authentication

| Name | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | Yes | `Bearer sk-...` (API Key) |

## Request Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | Yes | Fixed as `minimax/h3-max` |
| `prompt` | string | Conditional | Scene and motion description (required for text/reference) |
| `image_url` | string | Conditional | Image URL for image-to-video (automatically switches endpoint) |
| `video_url` | string | Conditional | Reference video URL for motion transfer |
| `duration` | number/string | No | Video duration (`5` or `10`, default `5`; 10s settles at 2.0x) |
| `aspect_ratio` | string | No | Aspect ratio: `"16:9"`, `"9:16"`, `"1:1"`, default `"16:9"` |
| `prompt_optimizer` | boolean | No | Enable LLM prompt enhancement, default `true` |

## Response

### 200 (Created)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Asynchronous task ID for polling |
| `status` | string | Initial task status (`queued`) |
| `created` | number | Task creation timestamp |

For polling format, see [Query Video Task](/en/api-reference/tasks/video-task). Errors are listed in the right panel and [Error Codes](/en/faqs/connection-usage).

<RequestExample>
