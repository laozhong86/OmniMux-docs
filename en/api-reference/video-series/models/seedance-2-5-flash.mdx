- Create: `POST /v1/video/generations` with `model` set to `seedance-2-5-flash`
- Async: poll [Video task](/en/api-reference/tasks/video-task) with the returned `task_id`
- Supports 480p and 720p output, 4–30s durations (`-1` auto-duration on `default`), synchronized audio, and multimodal references (image, video, audio)
- Groups: tokens using `auto` route automatically by `resolution` to `seedance-2-5-flash-480p` or `seedance-2-5-flash-720p` economy tiers; select `default` for `video_edit`, `video_extend`, or `-1` auto-duration
- Persist result URLs promptly (upstream links may expire)

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | Seedance |
| model | `seedance-2-5-flash` |

## Supported Modes

| Mode (`operation`) | Description |
| --- | --- |
| `text_to_video` | Text-to-video |
| `first_frame` | First-frame image-to-video |
| `first_last_frame` | First and last frame interpolation |
| `video_multi_ref` | Multimodal reference-to-video (up to 10 images, 5 videos, 5 audios) |
| `video_edit` | Video editing (`default` group only) |
| `video_extend` | Video extension (`default` group only) |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `seedance-2-5-flash` |
| `prompt` | string | yes | Video generation prompt |
| `duration` / `seconds` | integer | no | Output duration in seconds (integer 4–30; `-1` auto-duration on `default`) |
| `resolution` | string | no | Resolution: `480p` or `720p` (default `720p`) |
| `aspect_ratio` / `size` | string | no | Aspect ratio: `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, or `adaptive` |
| `generate_audio` | boolean | no | Generate synchronized audio, default `true` |
| `image_urls` | array | no | Reference image HTTPS URLs (up to 10) |
| `video_urls` | array | no | Reference video HTTPS URLs (up to 5) |
| `audio_urls` | array | no | Reference audio HTTPS URLs (up to 5) |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `pending` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).
