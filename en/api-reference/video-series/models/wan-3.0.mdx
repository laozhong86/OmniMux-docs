## Resolution selects the tier

`wan-3.0` keeps one public model ID, and the tier is never chosen through a model ID: the gateway selects the tier group from the request resolution, so callers neither need to nor should pick a group themselves.

| Tier | Group | Resolution | Price (CNY per second) |
| --- | --- | --- | --- |
| 720p tier | `wan-3.0-720p` | `720p` | **¥0.60/second** |
| 1080p tier | `wan-3.0-1080p` | `1080p` | **¥1.80/second** |

- The resolution is required: the tier selects the channel, so without a resolution — and without an explicit group — no channel is available and the request is rejected (`400`).
- Accepted resolution spellings: `720p` / `1080p` (case-insensitive), or an equivalent size such as `1280x720` or `1920x1080`; a size is classified by its shorter side, so landscape and portrait cost the same.
- Only the `720p` and `1080p` tiers are offered; any other resolution is rejected (`400`), and the error message lists the accepted values.
- Billing is per second, and public prices are quoted in CNY (RMB).
- Both `POST /v1/video/generations` and the console's `POST /pg/video/generations` select the tier group automatically; the latter accepts a browser session only and is not part of the token API surface.
- An explicit choice wins: when the caller sends the `X-Omnimux-Group` header, a body `group`, or a `model@group` suffix, that explicit group is used and automatic tier selection does not override it.

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `wan-3.0`, optionally with an `@group` suffix |
| `prompt` | string | conditional | Required for text-to-video |
| `duration` | integer | no | Duration in seconds, published envelope 4–30; lower with a reference video (≤ 15 seconds) |
| `seconds` | string | no | OpenAI-native spelling of the duration; **must be a string** (e.g. `"5"`) — a number is rejected before any plugin runs (`400`) |
| `resolution` / `size` | string | yes | `720p` or `1080p` (or an equivalent size); selects the tier, the channel and the price |
| `image` / `images` | string/array | no | Image-to-video references |

- A duration below 4 seconds or above 30 seconds is not accepted; requests carrying a reference video cap at 15 seconds.
- `duration` and `seconds` are alternatives for the same duration: send an integer for `duration` (`5`) and a string for `seconds` (`"5"`).
- Without a resolution — and without an explicit group — no channel is available, so the request is rejected (`400`) rather than silently billed at another tier's price.

## Billing

- Charged by the requested video duration, in CNY per second:
  - `720p` tier: **¥0.60/second**
  - `1080p` tier: **¥1.80/second**
- The base anchors the official 1080P list price of **¥1.20/second**; the 720p tier is 0.5× and the 1080p tier is 1.5×.
- Examples: `720p` / 5 seconds = ¥3.00; `1080p` / 5 seconds = ¥9.00.
- The public pricing endpoint and the pre-submission quote remain authoritative for any individual request.
