- Create: `POST /v1/video/generations` with `model` set to `kling-avatar`
- Async: poll [Video task](/en/api-reference/tasks/video-task) with returned `task_id`
- **Live catalog note:** Confirm whether `kling-avatar` is currently active on your token via the [OmniMux console](https://omnimux.ai/dashboard) or `GET /v1/models` before integrating. For live photo + audio lip-sync and digital human workflows, see [LTX digital human](/en/api-reference/video-series/models/ltx-2-3-kj) (`ltx-2-3-kj`) and [MiniMax H3 Video Line](/en/api-reference/video-series/models/minimax-h3-video) (`minimax-h3-video`, group `minimax-h3-video-digital-human`)
- Persist result URLs promptly (upstream links may expire)

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | Kling |
| model | `kling-avatar` |

## Live Lip-Sync & Digital Human Alternatives

| Model ID | Endpoint | Capabilities | Guide |
| --- | --- | --- | --- |
| `ltx-2-3-kj` | `POST /v1/video/generations` | Photo + audio lip-sync (`nodeInfoList`) | [LTX digital human](/en/api-reference/video-series/models/ltx-2-3-kj) |
| `minimax-h3-video` | `POST /v1/videos` | Digital human (`minimax-h3-video-digital-human` group, portrait + speech audio) | [MiniMax H3 Video Line](/en/api-reference/video-series/models/minimax-h3-video) |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

No dedicated model contract is published for `kling-avatar` on this gateway; confirm supported parameters with your active channel or `GET /v1/models`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | `kling-avatar` (when enabled in your live catalog) |
| `prompt` | string | conditional | Scene or motion instruction |
| `seconds` / `duration` | number | no | Duration in seconds (bounded) |
| `size` / `resolution` | string | no | Resolution (model-specific) |
| `image` / `images` | string/array | no | Reference portrait image URLs |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `queued` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).
