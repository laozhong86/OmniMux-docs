- Create: `POST /v1/video/generations` with `model` set to `minimax-h3-endframe`
- Async: poll [Video task](/en/api-reference/tasks/video-task) with returned `task_id`
- For unified frame-role selection (`image_with_roles`), see [MiniMax H3 Video Generation](/en/api-reference/video-series/models/minimax-h3); for the live `minimax-h3-video` first-last-frame scenario group on `POST /v1/videos`, see [MiniMax H3 Video Line](/en/api-reference/video-series/models/minimax-h3-video)
- Confirm live availability via the [OmniMux console](https://omnimux.ai/dashboard) or `GET /v1/models`, and persist result URLs promptly

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | MiniMax |
| model | `minimax-h3-endframe` |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `minimax-h3-endframe` |
| `prompt` | string | conditional | Scene and transition prompt guiding motion toward the end frame |
| `seconds` / `duration` | number | no | Duration in seconds (bounded) |
| `size` / `resolution` | string | no | Output resolution (model-specific) |
| `image` / `images` | string/array | no | Closing / reference frame image URLs |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `queued` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).
