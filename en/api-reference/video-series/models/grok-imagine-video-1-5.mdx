- Create: `POST /v1/video/generations` with `model` set to `grok-imagine-video-1-5`
- Async: poll [Video task](/en/api-reference/tasks/video-task) with returned `task_id`
- Supports `480p`, `720p`, and `1080p` resolutions, `1–15s` durations (default `8s`), `generate_audio` (default `false`), and `image_urls` reference generation (up to `3` reference audios of `<= 15s` on routes that enable audio references; reference videos are not supported)
- Confirm live pricing in the [OmniMux console](https://omnimux.ai/dashboard) or `GET /v1/models`
- Persist result URLs promptly (upstream links may expire)

## Identity

| Field | Value |
| --- | --- |
| Series | Video series |
| Brand | xAI |
| model | `grok-imagine-video-1-5` |

## Supported Modes

| Mode (`operation`) | Input Requirements | Aspect Ratio & Limits |
| --- | --- | --- |
| `text_to_video` | `prompt` | `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3` |
| `video_multi_ref` | `prompt` + `image_urls` (optional `audio_urls` on supported routes) | `image_urls` accepts JPEG/PNG/WebP URLs (`https://` required on APIMart routes); `audio_urls` accepts up to 3 clips (`<= 15s` each; not accepted on image-only upstream routes); `video_urls` is not supported |

## Endpoint

| Method | Path |
| --- | --- |
| `POST` | `/v1/video/generations` |
| `GET` | `/v1/video/generations/{task_id}` |

Base URL: `https://api.omnimux.ai`

## Authorizations

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | yes | `Bearer sk-...` (API key) |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `model` | string | yes | Must be `grok-imagine-video-1-5` |
| `prompt` | string | yes | Video generation prompt |
| `duration` / `seconds` | integer | no | Output duration in seconds (`1` to `15`, default `8`) |
| `resolution` | string | no | `480p`, `720p`, or `1080p` |
| `aspect_ratio` / `size` | string | no | `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, or `2:3` |
| `generate_audio` | boolean | no | Generate synchronized audio, default `false` |
| `image_urls` | array | no | Reference image URLs (`image/jpeg`, `image/png`, `image/webp`) for `video_multi_ref` |
| `audio_urls` | array | no | Optional reference audio URLs (`<= 3` clips, `<= 15s` each; route-dependent, omitted on image-only channels) |

## Response

### 200 (create)

| Field | Type | Description |
| --- | --- | --- |
| `task_id` | string | Task id for polling |
| `status` | string | e.g. `queued` / `processing` / `completed` |

See [Video task](/en/api-reference/tasks/video-task). Errors: right rail and [Error codes](/en/faqs/connection-usage).
