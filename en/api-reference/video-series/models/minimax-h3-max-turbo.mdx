Use text_to_video without media, or first_frame with exactly one image. Turbo does not support video_multi_ref. Use one field spelling per media kind. Replace legacy 720p with explicit 768P. Completed jobs without usable artifacts remain retryable; failure/cancellation takes precedence over stale artifacts. Status reads do not own billing settlement. Pricing follows the current catalog; no fixed generation latency is guaranteed.
