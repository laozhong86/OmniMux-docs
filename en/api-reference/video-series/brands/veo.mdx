Brand：**Veo / Omni Flash**（Google）

Google video family (Veo / Omni Flash). Typically async.

## Recommended protocols

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/v1/video/generations` | Unified video task |
| `GET` | `/v1/video/generations/{task_id}` | Task status |

Snapshot examples only — **not** a guarantee of availability. Use `GET /v1/models` and the Model Square.

## Example call

```bash
curl -sS https://api.omnimux.ai/v1/video/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo_3_1",
    "prompt": "slow pan across a product"
  }'
```
