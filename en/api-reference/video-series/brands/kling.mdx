Brand：**Kling**（Kling）

Kling-native paths are public. Model ids follow `GET /v1/models` and channel config.

## Recommended protocols

| Method | Path | Notes |
| --- | --- | --- |
| `POST` | `/kling/v1/videos/text2video` | Text-to-video |
| `GET` | `/kling/v1/videos/text2video/{task_id}` | T2V status |
| `POST` | `/kling/v1/videos/image2video` | Image-to-video |
| `GET` | `/kling/v1/videos/image2video/{task_id}` | I2V status |
| `POST` | `/v1/video/generations` | Unified video tasks (when mapped) |

## Example models

This brand is path/channel-oriented; list model ids with `GET /v1/models`.

## Example call

```bash
curl -sS https://api.omnimux.ai/kling/v1/videos/text2video \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_MODEL",
    "prompt": "slow pan across a product"
  }'
```
