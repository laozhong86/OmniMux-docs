Discover video models by **brand / product family**, then call **shared or channel-native protocols** (`sk-` gateway). Most flows are **async**.

## Brands

| Brand | Notes |
| --- | --- |
| [Kling](/en/api-reference/video-series/brands/kling) | Native text2video / image2video paths |
| [Veo / Omni Flash](/en/api-reference/video-series/brands/veo) | Google video family |
| [Grok Imagine](/en/api-reference/video-series/brands/grok-imagine) | xAI video |
| [MiniMax](/en/api-reference/video-series/brands/minimax) | Hailuo / h3 tasks (incl. async) |
| [LTX](/en/api-reference/video-series/brands/ltx) | LTX apps |
| [Jimeng](/en/api-reference/video-series/brands/jimeng) | Jimeng-native `/jimeng/` |
| [Sora / Videos](/en/api-reference/video-series/brands/sora) | OpenAI Videos-style `/v1/videos` |

Model ids follow `GET /v1/models`. When unsure, prefer `POST /v1/video/generations` (unified tasks).

## Protocol endpoints (this sidebar group)

Unified tasks, Videos-style, Kling, and Jimeng try-it ops nest under this group.
