<Note>
Base URL: `https://api.omnimux.ai` (OpenAI-compatible clients usually use `https://api.omnimux.ai/v1`). Create a `sk-` key in the [console](https://omnimux.ai/dashboard). Model ids: console or `GET /v1/models`.
</Note>


## Prep

1. Install [AnythingLLM](https://anythingllm.com/)
2. OmniMux API key

## Setup

1. Settings → **LLM Preference**
2. Provider: **Generic OpenAI** / OpenAI-compatible
3. Base URL `https://api.omnimux.ai/v1`, Key `sk-...`
4. Set model name from OmniMux catalog

## Verify

Chat in a workspace.
