<Note>
Base URL: `https://api.omnimux.ai` (OpenAI-compatible clients usually use `https://api.omnimux.ai/v1`). Create a `sk-` key in the [console](https://omnimux.ai/dashboard). Model ids: console or `GET /v1/models`.
</Note>


## Prep

1. Install [Immersive Translate](https://immersivetranslate.com/)
2. OmniMux API key

## Setup

1. Extension settings → **Translation service** → OpenAI / custom OpenAI
2. Key `sk-...`
3. API URL `https://api.omnimux.ai/v1`
4. Model id from OmniMux text catalog

## Verify

Translate a page once.
