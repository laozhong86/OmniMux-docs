<Note>
Base URL: `https://api.omnimux.ai` (OpenAI-compatible clients usually use `https://api.omnimux.ai/v1`). Create a `sk-` key in the [console](https://omnimux.ai/dashboard). Model ids: console or `GET /v1/models`.
</Note>


## Prep

1. Install ZCode (official channel)
2. OmniMux API key

## Setup

1. Settings → **AI / Models / OpenAI-compatible**
2. Base URL `https://api.omnimux.ai/v1`
3. Key `sk-...`
4. Model id from OmniMux catalog

## Verify

Trigger completion or chat once.
