<Note>
Base URL: `https://api.omnimux.ai` (OpenAI-compatible clients usually use `https://api.omnimux.ai/v1`). Create a `sk-` key in the [console](https://omnimux.ai/dashboard). Model ids: console or `GET /v1/models`.
</Note>


## Prep

1. [Dify](https://dify.ai/) cloud or self-host
2. OmniMux API key

## Setup

1. Avatar → **Settings** → **Model Provider**
2. OpenAI / OpenAI-API-compatible custom endpoint
3. Key `sk-...`, Base URL `https://api.omnimux.ai/v1`
4. Add model names matching OmniMux ids

## Verify

Chat in an app with that model.
