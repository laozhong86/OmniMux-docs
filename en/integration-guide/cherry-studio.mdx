<Note>
Base URL: `https://api.omnimux.ai` (OpenAI-compatible clients usually use `https://api.omnimux.ai/v1`). Create a `sk-` key in the [console](https://omnimux.ai/dashboard). Model ids: console or `GET /v1/models`.
</Note>


## Prep

1. Install [Cherry Studio](https://cherry-ai.com/)
2. Get an OmniMux API key

## Setup

1. Settings → **Model service** → **Add**
2. Provider type: **OpenAI**-compatible
3. API Key + Base URL `https://api.omnimux.ai/v1`
4. Add model ids and enable them

## Verify

Start a chat with the new model.
