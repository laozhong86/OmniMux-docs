OmniMux 是为 Agent 打造的社交媒体自动化运营基础设施，并以**统一 AI 模型网关**交付调用能力：多上游聚合到同一入口，支持 **OpenAI 兼容**、**Claude Messages**、**Gemini** 等格式，并提供计费、令牌与渠道管理。

生产入口：控制台 [geminix.cc](https://geminix.cc) · API `https://api.geminix.cc` · 文档 [docs.geminix.cc](https://docs.geminix.cc)。

## Base URL

生产环境网关默认：

```text
https://api.geminix.cc
```

将现有 OpenAI SDK 的 `base_url` / `BASE_URL` 改为 `https://api.geminix.cc/v1`，并使用控制台创建的 API Key，即可迁移大部分 Chat 调用。

<Tip>
  控制台与 API 域名分离：控制台 [geminix.cc/dashboard](https://geminix.cc/dashboard)，API 使用 `api.geminix.cc`。
</Tip>
