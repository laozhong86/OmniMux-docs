OmniMux 是统一 AI 模型网关。把多个上游供应商聚合到同一入口，支持 **OpenAI 兼容**、**Claude Messages**、**Gemini** 等格式，并提供计费、令牌与渠道管理。

## Base URL

生产环境网关默认：

```text
https://api.omnimux.ai
```

将现有 OpenAI SDK 的 `base_url` / `BASE_URL` 改为上述地址，并使用控制台创建的 API Key 即可迁移大部分 Chat 调用。
