## Base URL

```text
https://api.omnimux.ai
```

OpenAI 兼容 SDK 常填：

```text
https://api.omnimux.ai/v1
```

鉴权：`Authorization: Bearer sk-...`。详见 [鉴权](/cn/guides/authentication)。

## OpenAI 兼容

| 能力 | 方法 | 路径 |
| --- | --- | --- |
| Chat Completions | `POST` | `/v1/chat/completions` |
| Completions | `POST` | `/v1/completions` |
| Responses | `POST` | `/v1/responses` |
| Responses compact | `POST` | `/v1/responses/compact` |
| Embeddings | `POST` | `/v1/embeddings` |
| Moderations | `POST` | `/v1/moderations` |
| Rerank | `POST` | `/v1/rerank` |
| 模型列表 | `GET` | `/v1/models` |
| Realtime | `GET` | `/v1/realtime`（WebSocket 升级，以线上为准） |
| 图像 | `POST` | `/v1/images/generations` · `/v1/images/edits` |
| 音频 | `POST` | `/v1/audio/*` |
| 视频（统一 / Sora 风格） | `POST`/`GET` | `/v1/video/generations` · `/v1/videos` |

## Anthropic 兼容

| 能力 | 方法 | 路径 |
| --- | --- | --- |
| Messages | `POST` | `/v1/messages` |

## Gemini 风格

| 能力 | 方法 | 路径 |
| --- | --- | --- |
| 模型列表 | `GET` | `/v1beta/models` |
| generateContent | `POST` | `/v1beta/models/{model}:generateContent` |
| Embeddings（引擎路径） | `POST` | `/v1/engines/{model}/embeddings` |
