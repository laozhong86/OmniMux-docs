本页是 **语言系列** 下的协议索引。品牌发现请先看：

**[语言系列](/cn/api-reference/text-series/overview)** → Claude / Gemini / GPT / Grok / …

## Base URL

```text
https://api.omnimux.ai
```

鉴权：`Authorization: Bearer sk-...`。

## 常用协议

| 能力 | 方法 | 路径 |
| --- | --- | --- |
| Chat Completions | `POST` | `/v1/chat/completions` |
| Completions | `POST` | `/v1/completions` |
| Responses | `POST` | `/v1/responses` |
| Responses compact | `POST` | `/v1/responses/compact` |
| Claude Messages | `POST` | `/v1/messages` |
| 模型列表 | `GET` | `/v1/models` |
| Gemini 模型列表 | `GET` | `/v1beta/models` |
| Gemini generateContent | `POST` | `/v1beta/models/{model}:generateContent` |
| Embeddings | `POST` | `/v1/embeddings` |
| Moderations | `POST` | `/v1/moderations` |
| Rerank | `POST` | `/v1/rerank` |
| Realtime | `GET` | `/v1/realtime` |

侧栏 **语言系列 → 协议接口** 下可对上述路径 try-it。
