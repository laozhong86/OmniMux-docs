- 账户管理用户 API
- 鉴权多为 access token + `New-Api-User`（设备码流程见对应页）

## 身份

| 字段 | 值 |
| --- | --- |
| 系列 | 账户管理 |
| 能力 | 设备码登录 |

## 接口

| 方法 | 路径 |
| --- | --- |
| `GET` | `说明` |

Base URL：`https://omnimux.ai`

## 鉴权

| 名称 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `Authorization` | header | string | 是 | `Bearer <access_token>`（用户 access token） |
| `New-Api-User` | header | string | 是 | 当前用户 id |

## 请求体 / 参数

以右栏 cURL 与线上为准。

## 响应

### 200

成功时返回账户相关字段（如 `quota` / `used_quota`）。错误见右栏与 [错误码](/cn/api-reference/errors)。

<Panel>

<RequestExample>

```bash curl --request POST \
  --url https://omnimux.ai/api/user/device/code \
  --header 'Content-Type: application/json' \
  --data '{"client_name":"my-cli"}'
```

```bash curl --request POST \
  --url https://omnimux.ai/api/user/device/token \
  --header 'Content-Type: application/json' \
  --data '{"device_code":"<device_code>","grant_type":"urn:ietf:params:oauth:grant-type:device_code"}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "success": true,

```

```json pending

```

</ResponseExample>
