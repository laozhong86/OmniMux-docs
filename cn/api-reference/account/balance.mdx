| 字段 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `https://omnimux.ai/api/user/self` |
| 鉴权 | access token |

## 请求示例

```bash
curl --request GET \
  --url https://omnimux.ai/api/user/self \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>'
```
