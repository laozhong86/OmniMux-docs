---
title: "列出账户"
description: "GET /api/social/v1/accounts"
---

| 字段 | 值 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `https://omnimux.ai/api/social/v1/accounts` |
| 鉴权 | access token + `New-Api-User` |

## 请求示例

<CodeGroup>
```bash cURL
curl --request GET \
  --url https://omnimux.ai/api/social/v1/accounts \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json'
```
</CodeGroup>
