---
title: "断开账户"
description: "DELETE /api/social/v1/accounts/{id}"
---

| 字段 | 值 |
| --- | --- |
| 方法 | `DELETE` |
| 路径 | `https://omnimux.ai/api/social/v1/accounts/{id}` |
| 鉴权 | access token + `New-Api-User` |

## 请求示例

<CodeGroup>
```bash cURL
curl --request DELETE \
  --url https://omnimux.ai/api/social/v1/accounts/{id} \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json'
```
</CodeGroup>
