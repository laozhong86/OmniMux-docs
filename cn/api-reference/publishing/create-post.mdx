| 字段 | 值 |
| --- | --- |
| 方法 | `POST` |
| 路径 | `https://omnimux.ai/api/social/v1/posts` |
| 鉴权 | access token + `New-Api-User` |

## 请求示例

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://omnimux.ai/api/social/v1/posts \
  --header 'Authorization: Bearer <access_token>' \
  --header 'New-Api-User: <user_id>' \
  --header 'Content-Type: application/json' \
  --data '{"account_ids":[1],"text":"hello","media_items":[{"url":"https://example.com/a.png"}]}'
```
</CodeGroup>
