图像能力走 **AI 网关**（`sk-` Bearer），Base URL：

```text
https://api.omnimux.ai
```

## 你能做什么

| 能力 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 文生图 | `POST` | `/v1/images/generations` | OpenAI 风格；部分渠道同步返回 URL，部分返回 `task_id` |
| 图编辑 | `POST` | `/v1/images/edits` | 参考图 + 提示词编辑（渠道相关） |

创建后若为异步，按 [异步任务](/cn/api-reference/cross-cutting/async-tasks) 轮询。公开 OpenAPI **可能尚未**列出全部任务查询路径；以线上响应中的 `task_id` / 状态字段为准。

## 鉴权

```http
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json
```

## 快速示例

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_IMAGE_MODEL",
    "prompt": "a product photo on white background",
    "n": 1
  }'
```

`model` 必须是你账户可用的图像模型（`GET /v1/models` 或控制台模型广场）。文档中的示例名 **不代表** 线上一定可用。
