## 调用

- Base：`https://api.omnimux.ai`
- 鉴权：`sk-` Bearer
- `POST /v1/images/generations` 或 `/v1/images/edits`

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"zimage-makeup","prompt":"a product on white background","n":1}'
```

异步渠道请按返回 `task_id` 轮询（见 [任务管理](/cn/api-reference/tasks/overview)）。
