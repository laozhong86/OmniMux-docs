品牌：**GPT Image**（OpenAI）

OpenAI 图像系列。`model` 填 `gpt-image2` 或 `gpt-image2-hd`（以可用列表为准）。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | 文生图 |
| `POST` | `/v1/images/edits` | 图编辑 |

## 示例 model

| model |
| --- |
| `gpt-image2-hd` |
| `gpt-image2` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image2-hd",
    "prompt": "a product on white background",
    "n": 1
  }'
```
