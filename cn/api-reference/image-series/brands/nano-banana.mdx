品牌：**Nano Banana**（Google）

Google 图像品牌。是否异步取决于渠道；见 [异步任务](/cn/api-reference/cross-cutting/async-tasks)。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | OpenAI 图像（视渠道） |
| `POST` | `/v1beta/models/{model}:generateContent` | Gemini 原生出图 |

## 示例 model

| model |
| --- |
| `nano_banana_pro` |
| `nano_banana_2` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "nano_banana_pro",
    "prompt": "a product on white background",
    "n": 1
  }'
```
