品牌：**Z Image**（GxgenAI）

GxgenAI Z Image 相关应用；`*-async` 为异步型号时按任务轮询。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/images/generations` | 图像生成 / 异步任务 |

## 示例 model

| model |
| --- |
| `zimage-makeup` |
| `zimage-makeup-async` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/images/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "zimage-makeup",
    "prompt": "a product on white background",
    "n": 1
  }'
```
