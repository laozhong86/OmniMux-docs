| 字段 | 值 |
| --- | --- |
| 方法 | `GET` |
| URL | `https://api.omnimux.ai/v1/images/generations/{task_id}` |
| 鉴权 | `sk-` Bearer |

## 请求示例

```bash
curl --request GET \
  --url https://api.omnimux.ai/v1/images/generations/$TASK_ID \
  --header 'Authorization: Bearer <token>'
```
