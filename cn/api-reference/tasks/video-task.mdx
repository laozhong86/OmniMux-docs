> - 用于 **视频系列** 创建接口返回的 `task_id`（`POST /v1/video/generations`）
> - 与 OpenAI 兼容路径 `/v1/videos/*` **不是同一套接口**
> - 状态：`queued` / `in_progress` / `completed` / `failed`（以线上为准）

Base URL：`https://api.omnimux.ai` · 鉴权：`Authorization: Bearer sk-...`
