视频能力按 **品牌/产品族** 发现，再落到 **共用或渠道原生协议接口**（`sk-` 网关）。多数为 **异步** 任务。

## 品牌

| 品牌 | 说明 |
| --- | --- |
| [Kling](/cn/api-reference/video-series/brands/kling) | 原生 text2video / image2video 路径 |
| [Veo / Omni Flash](/cn/api-reference/video-series/brands/veo) | Google 视频家族 |
| [Grok Imagine](/cn/api-reference/video-series/brands/grok-imagine) | xAI 视频 |
| [MiniMax](/cn/api-reference/video-series/brands/minimax) | Hailuo / h3 任务（含 async） |
| [LTX](/cn/api-reference/video-series/brands/ltx) | LTX 应用 |
| [即梦](/cn/api-reference/video-series/brands/jimeng) | 即梦原生 `/jimeng/` |
| [Sora / Videos](/cn/api-reference/video-series/brands/sora) | OpenAI Videos 风格 `/v1/videos` |

model id 以 `GET /v1/models` 为准。不确定时优先 `POST /v1/video/generations`（统一任务）。

## 协议接口（侧栏本组）

统一任务、Videos 风格、Kling、即梦等 try-it 挂在本组下方。
