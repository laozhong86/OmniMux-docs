视频生成走 **AI 网关**（`sk-` Bearer），Base URL：

```text
https://api.omnimux.ai
```

多数视频接口是 **异步**：创建 → `task_id` → 轮询状态 → 取结果 URL。见 [异步任务](/cn/api-reference/cross-cutting/async-tasks)。

## 主路径（推荐优先）

| 能力 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 创建任务 | `POST` | `/v1/video/generations` | 统一异步视频入口（多渠道 / 模型） |
| 查询任务 | `GET` | `/v1/video/generations/{task_id}` | 状态与结果 |
| OpenAI Videos 风格创建 | `POST` | `/v1/videos` | 兼容部分 Sora 风格客户端 |
| 查询 / 内容 | `GET` | `/v1/videos/{task_id}` · `/v1/videos/{task_id}/content` | 状态与内容 |

## 渠道原生路径（按模型 / 上游）

| 系列 | 创建 | 查询 |
| --- | --- | --- |
| Kling 文生视频 | `POST /kling/v1/videos/text2video` | `GET .../text2video/{task_id}` |
| Kling 图生视频 | `POST /kling/v1/videos/image2video` | `GET .../image2video/{task_id}` |
| 即梦 | `POST /jimeng/` | 以响应约定为准 |

同一账号上 **可用模型与路径以渠道配置为准**。不确定时先 `GET /v1/models`，并优先用 `/v1/video/generations`（若该模型挂在统一任务适配器上）。

## 鉴权

```http
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json
```

## 快速示例

```bash
# 创建
curl -sS https://api.omnimux.ai/v1/video/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_VIDEO_MODEL",
    "prompt": "slow pan across a product on a table"
  }'

# 查询（task_id 来自创建响应）
curl -sS "https://api.omnimux.ai/v1/video/generations/$TASK_ID" \
  -H "Authorization: Bearer $OMNIMUX_API_KEY"
```
