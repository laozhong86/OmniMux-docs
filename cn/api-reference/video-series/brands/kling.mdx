品牌：**Kling**（Kling）

Kling 原生路径已开放。具体 model id 以 `GET /v1/models` 与渠道配置为准。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/kling/v1/videos/text2video` | 文生视频 |
| `GET` | `/kling/v1/videos/text2video/{task_id}` | 文生视频状态 |
| `POST` | `/kling/v1/videos/image2video` | 图生视频 |
| `GET` | `/kling/v1/videos/image2video/{task_id}` | 图生视频状态 |
| `POST` | `/v1/video/generations` | 统一视频任务（若模型挂在此入口） |

## 示例 model

此品牌以**路径/渠道**为主；请用 `GET /v1/models` 查当前可用 model id。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/kling/v1/videos/text2video \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_MODEL",
    "prompt": "slow pan across a product"
  }'
```
