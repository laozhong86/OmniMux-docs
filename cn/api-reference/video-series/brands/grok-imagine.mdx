品牌：**Grok Imagine**（xAI）

xAI Grok Imagine 视频。文本 Grok 见 [语言 · Grok](/cn/api-reference/text-series/brands/grok)。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/video/generations` | 统一视频任务 |
| `GET` | `/v1/video/generations/{task_id}` | 任务状态 |

## 示例 model

| model |
| --- |
| `grok-imagine-video-1.5` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/video/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-video-1.5",
    "prompt": "slow pan across a product"
  }'
```
