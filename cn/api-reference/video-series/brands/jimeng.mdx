品牌：**即梦**（Jimeng）

即梦原生路径。模型可用性以渠道与 `GET /v1/models` 为准。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/jimeng/` | 即梦原生格式 |
| `POST` | `/v1/video/generations` | 统一入口（若已映射） |

## 示例 model

此品牌以**路径/渠道**为主；请用 `GET /v1/models` 查当前可用 model id。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/jimeng/ \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_MODEL",
    "prompt": "slow pan across a product"
  }'
```
