品牌：**MiniMax**（MiniMax / GxgenAI）

MiniMax 视频（含 async 变体）。文本 MiniMax 见 [语言 · MiniMax](/cn/api-reference/text-series/brands/minimax)。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/video/generations` | 统一视频 / AI App 任务 |
| `GET` | `/v1/video/generations/{task_id}` | 任务状态 |

## 示例 model

| model |
| --- |
| `minimax-h3-t2v` |
| `minimax-h3-t2v-async` |
| `minimax-h3-flf` |
| `minimax-h3-flf-async` |
| `minimax-h3-fl2va` |
| `minimax-h3-fl2va-async` |
| `minimax-h3-endframe` |
| `minimax-h3-endframe-async` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/video/generations \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-h3-t2v",
    "prompt": "slow pan across a product"
  }'
```
