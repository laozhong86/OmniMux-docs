AI 网关（`sk-`）与多数用户 API 共用下列 HTTP 语义。具体业务 message 以线上为准。

## 状态码一览

| HTTP | 含义 |
| --- | --- |
| `200` | 成功 |
| `400` | 请求参数错误 |
| `401` | 未鉴权 / Token 无效 |
| `403` | 无权限（模型未授权、IP 限制等） |
| `404` | 路径或资源不存在 |
| `429` | 限流 |
| `500` | 服务内部错误 |
| `502` | 上游错误 / Bad Gateway |
| `503` | 服务暂不可用 |
