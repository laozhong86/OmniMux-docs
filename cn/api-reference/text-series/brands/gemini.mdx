品牌：**Gemini**（Google）

文本对话常用 Chat Completions。出图能力（如 Nano Banana）见 [图像 · Nano Banana](/cn/api-reference/image-series/brands/nano-banana)。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/chat/completions` | OpenAI Chat 兼容 |
| `POST` | `/v1beta/models/{model}:generateContent` | Gemini 原生（含部分多模态） |
| `GET` | `/v1beta/models` | Gemini 格式模型列表 |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/chat/completions \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.6-flash",
    "messages": [{
      "role": "user",
      "content": "Hello"
    }]
  }'
```
