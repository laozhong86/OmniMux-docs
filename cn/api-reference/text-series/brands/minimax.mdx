品牌：**MiniMax**（MiniMax）

MiniMax 文本。视频 Hailuo 见 [视频 · MiniMax](/cn/api-reference/video-series/brands/minimax)。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/chat/completions` | Chat Completions |

## 示例 model

| model |
| --- |
| `minimax-m3` |
| `minimax-m2.7` |
| `minimax-m2.5` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/chat/completions \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-m3",
    "messages": [{
      "role": "user",
      "content": "Hello"
    }]
  }'
```
