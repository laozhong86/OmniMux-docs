品牌：**GPT**（OpenAI）

OpenAI 协议族主入口。图像模型见 [图像 · GPT Image](/cn/api-reference/image-series/brands/gpt-image)。

## 推荐协议

| 方法 | Path | 说明 |
| --- | --- | --- |
| `POST` | `/v1/chat/completions` | Chat Completions |
| `POST` | `/v1/responses` | Responses API |
| `POST` | `/v1/responses/compact` | Responses compact |

## 示例 model

| model |
| --- |
| `gpt-5.6-terra` |
| `gpt-5.6-sol` |
| `gpt-5.6-luna` |
| `gpt-5.5` |
| `gpt-5.4` |
| `gpt-5.4-mini` |

以上为文档快照示例，**不代表**你的账户一定开通。请以 `GET /v1/models` 与控制台模型广场为准。

## 调用示例

```bash
curl -sS https://api.omnimux.ai/v1/chat/completions \
  -H "Authorization: Bearer $OMNIMUX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "messages": [{
      "role": "user",
      "content": "Hello"
    }]
  }'
```
