语言能力按 **品牌/产品族** 发现，再落到 **共用协议接口**（`sk-` 网关）。

品牌页中的 model 列表为快照示例；**以** `GET /v1/models` **与控制台为准**。

## 协议 vs 品牌

- **品牌页**：选模型族、看推荐协议与示例 id  
- **协议接口**（侧栏本组下方）：Chat / Messages / Responses / 模型列表等 try-it  

同一 `POST /v1/chat/completions` 可服务多个品牌，差在请求里的 `model`。
