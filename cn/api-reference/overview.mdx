OmniMux 对外集成有 **两条主入口**：

| 入口 | Base URL | 凭证 | 典型用途 |
| --- | --- | --- | --- |
| **AI 网关** | `https://api.omnimux.ai` | `sk-` Bearer | 文本 / 图像 / 视频 / 音频 |
| **用户 API** | `https://omnimux.ai` | access token + `New-Api-User` | Social Ops、设备码登录 |

控制台：[omnimux.ai/dashboard](https://omnimux.ai/dashboard) · 文档：[docs.omnimux.ai](https://docs.omnimux.ai)

## 怎么读本手册

侧栏信息架构（对齐 Evolink 式发现，落在 OmniMux 网关现实上）：

```text
系列（语言 / 图像 / 视频 / 音频）
  ├─ 品牌 / 产品族导读（Claude、Nano Banana、Kling…）
  └─ 协议接口 try-it（共用 /v1/* 或渠道原生 path）
Social Ops（独立用户 API）
通用约定 · 附录
```

- **品牌页**：选模型族、示例 `model`、推荐协议  
- **协议接口**：真正的 HTTP 契约与 try-it（多品牌共用同一 path，差在 `model`）  
- **不抄** 线上不存在的竞品品牌名；品牌列表以本站定价 / `GET /v1/models` 为准  

收录边界见 [文档覆盖说明](/cn/api-reference/coverage)。

## AI 网关快速鉴权

```http
Authorization: Bearer sk-xxxxxxxx
Content-Type: application/json
```

OpenAI 兼容 SDK Base URL 通常为 `https://api.omnimux.ai/v1`。

## 模型 ID

```bash
curl https://api.omnimux.ai/v1/models \
  -H "Authorization: Bearer $OMNIMUX_API_KEY"
```

文档里的示例 model **不是** 可用性证明。
