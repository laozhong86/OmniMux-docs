公开站 [docs.omnimux.ai](https://docs.omnimux.ai) **不承诺**收录代码仓库里的每一条路由。集成方应以本站「承诺公开」页面为准。

## 三级收录

| 级别 | 含义 | 文档形态 |
| --- | --- | --- |
| **A. 承诺公开** | 第三方 / Agent 主集成路径 | 专页和/或 OpenAPI 试调用 |
| **B. 有限公开** | CLI 或控制台辅助，集成偶尔需要 | 短页或概览表 |
| **C. 不收录** | Admin、内部回调实现细节、弃用路径 | 仅在此声明 |

## 当前归类

| API 族 | 级别 | 文档入口 |
| --- | --- | --- |
| AI 网关 `/v1/*`（Chat、图像、视频、音频等） | A | [协议集成](/cn/api-reference/protocol/overview) · [附录 OpenAPI](/cn/api-reference/appendix/openapi) |
| 图像 / 视频 / 音频 **系列导读** | A | [图像](/cn/api-reference/image-series/overview) · [视频](/cn/api-reference/video-series/overview) · [音频](/cn/api-reference/audio-series/overview) |
| Social Ops `/api/social/v1/*` | A | [社媒运营](/cn/api-reference/social-ops) |
| 设备码登录 `/api/user/device/*` | A | [设备码登录](/cn/api-reference/cross-cutting/device-login) |
| 异步任务轮询约定 | A | [异步任务](/cn/api-reference/cross-cutting/async-tasks) |
| 公开定价 `GET /api/pricing`、余额 `GET /api/user/self` | B | 计划补页；暂可用 CLI `omnimux pricing` / `balance` |
| 用户令牌 CRUD `/api/token/*` | B | 控制台 **令牌** 为主；HTTP 细节后置 |
| 注册登录 UI、2FA、充值支付回调、签到 | C | 控制台使用，不写集成专页 |
| Admin / 渠道 / 系统选项 | C | 不公开 |

## 说明

- **未在侧栏列出 ≠ 线上不存在**，但不在 A 类则不承诺稳定对外集成文档。
- 新增用户向 HTTP 能力时，Agent 须在真实 smoke 后更新本站（见仓库 `AGENTS.md`）。
- Social Ops 使用 **access token**，AI 网关使用 **`sk-`**，勿混用。见 [鉴权](/cn/guides/authentication)。
