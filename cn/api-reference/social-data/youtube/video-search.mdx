| 主要业务字段 | `search_query` |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/chat/completions` |

Base：`https://api.omnimux.ai` · 鉴权：`sk-` · dummy `messages` + 业务字段 top-level



<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.omnimux.ai/v1/chat/completions \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "youtube-search",
  "messages": [
    { "role": "user", "content": "." }
  ],
  "search_query": "openai"
}'
```

</RequestExample>
