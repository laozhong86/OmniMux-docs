| 字段 | 值 |
| --- | --- |
| 系列 | 社交数据 |
| 平台 | TikTok |
| 能力 | 用户作品列表 |
| model | `tiktok-posts` |
| 主要业务字段 | `unique_id` |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/chat/completions` |

Base：`https://api.omnimux.ai` · 鉴权：`sk-` · dummy `messages` + 业务字段 top-level

## 请求示例

<CodeGroup>
```bash cURL
curl --request POST \
  --url https://api.omnimux.ai/v1/chat/completions \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "tiktok-posts",
  "messages": [
    { "role": "user", "content": "." }
  ],
  "unique_id": "tiktok"
}'
```
</CodeGroup>
