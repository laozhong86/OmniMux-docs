| 主要业务字段 | `tweet_id` |

## 接口

| 方法 | 路径 |
| --- | --- |
| `POST` | `/v1/chat/completions` |

Base：`https://api.omnimux.ai` · 鉴权：`sk-` · dummy `messages` + 业务字段 top-level



<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.omnimux.ai/v1/chat/completions \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
  "model": "x-tweet",
  "messages": [
    { "role": "user", "content": "." }
  ],
  "tweet_id": "2081809802515136887"
}'
```

</RequestExample>
