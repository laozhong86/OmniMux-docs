## 生产地址

| 用途 | 地址 |
| --- | --- |
| 控制台 | [https://omnimux.ai/dashboard](https://omnimux.ai/dashboard) |
| API Base URL | `https://api.omnimux.ai` |
| OpenAI 兼容（SDK 常用） | `https://api.omnimux.ai/v1` |
| 文档 | [https://docs.omnimux.ai](https://docs.omnimux.ai) |

鉴权头统一为：

```http
Authorization: Bearer sk-xxxxxxxx
```

## 填哪个值？

| 场景 | 填什么 |
| --- | --- |
| OpenAI 官方 SDK / 多数兼容客户端 | `https://api.omnimux.ai/v1` |
| 自己拼完整路径（如 curl） | `https://api.omnimux.ai/v1/chat/completions` |
| 只问「网关根地址」 | `https://api.omnimux.ai` |

**不要**把控制台地址 `https://omnimux.ai` 当成 API Base URL。网关请使用 `https://api.omnimux.ai`（SDK 常用 `https://api.omnimux.ai/v1`）。

## 常见客户端

### 1) 环境变量

```bash
export OMNIMUX_API_KEY="sk-xxxxxxxx"
export OPENAI_API_KEY="$OMNIMUX_API_KEY"
export OPENAI_BASE_URL="https://api.omnimux.ai/v1"
```

### 2) Python（openai）

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-xxxxxxxx",
    base_url="https://api.omnimux.ai/v1",
)
```

### 3) Node.js（openai）

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.OMNIMUX_API_KEY,
  baseURL: "https://api.omnimux.ai/v1",
});
```

### 4) curl

```bash
curl https://api.omnimux.ai/v1/models \
  -H "Authorization: Bearer $OMNIMUX_API_KEY"
```

### 5) Cherry Studio / 类 OpenAI 客户端

1. 打开设置 → 模型服务 / API  
2. **API 地址 / Base URL**：`https://api.omnimux.ai/v1`  
3. **API Key**：控制台创建的 `sk-...`  
4. 保存后拉模型列表或发一条对话

### 6) Cursor / Continue 等编辑器

在 Provider 配置里：

- Base URL：`https://api.omnimux.ai/v1`  
- API Key：你的令牌  

具体字段名可能是 `OpenAI Base URL`、`Override Base URL` 等，语义相同。

## 自检

```bash
# 1) 状态
curl -sS https://api.omnimux.ai/api/status | head -c 200

# 2) 模型列表（需有效 Key）
curl -sS https://api.omnimux.ai/v1/models \
  -H "Authorization: Bearer $OMNIMUX_API_KEY"
```

| 现象 | 处理 |
| --- | --- |
| DNS / 无法解析 | 为 `api.omnimux.ai` 配 CNAME（见运维 DNS） |
| 401 | Key 错误或未带 `Authorization` |
| 404 on `/v1/...` | Base URL 多写/少写了 `/v1`；SDK 用带 `/v1`，完整路径不要重复 `/v1` |
| 连上控制台但 API 失败 | 控制台是 `omnimux.ai`，API 应用 `api.omnimux.ai` |
