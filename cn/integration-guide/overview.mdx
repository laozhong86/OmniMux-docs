把常用 **Coding CLI / Agent / 桌面客户端** 的 Base URL 与 API Key 指向 OmniMux，即可在本地工具链中使用控制台已开通的模型。

## 通用配置

| 项 | 值 |
| --- | --- |
| 控制台 | [omnimux.ai/dashboard](https://omnimux.ai/dashboard) |
| API Base URL | `https://api.omnimux.ai` |
| OpenAI 兼容（多数 SDK / CLI） | `https://api.omnimux.ai/v1` |
| Claude / Anthropic 兼容根地址 | `https://api.omnimux.ai` |
| Gemini 兼容 | `https://api.omnimux.ai/v1beta` |
| API Key | 控制台创建的 `sk-...` |

鉴权与模型选择见 [鉴权](/cn/guides/authentication)、[模型列表](/cn/guides/models)。

## 接入检查清单

1. 在控制台创建令牌，并确认模型范围  
2. 客户端 Base URL 使用 `api.omnimux.ai`（不要填控制台域名）  
3. 用 `GET /v1/models` 或控制台核对真实 `model` ID  
4. 先发一条极短对话验证，再挂到 Agent / 渠道  

完整 HTTP 接口见 [API 手册](/cn/api-reference/overview)。
