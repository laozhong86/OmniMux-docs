<Note>
Base URL：`https://api.omnimux.ai`（OpenAI 兼容客户端通常填 `https://api.omnimux.ai/v1`）。在 [控制台](https://omnimux.ai/dashboard) 创建 `sk-` API Key。模型 ID 以控制台或 `GET /v1/models` 为准。
</Note>


## 准备

1. 安装 ZCode（以官方渠道为准）
2. OmniMux API Key

## 配置

1. 打开 ZCode 设置中的 **AI / 模型 / OpenAI 兼容** 配置
2. API Base URL：`https://api.omnimux.ai/v1`
3. API Key：`sk-...`
4. 模型 ID：从 OmniMux 模型列表选择

## 验证

在编辑器内触发补全或对话，确认响应来自 OmniMux。
